### `src/components/isp/_shared/tree-view/00-as-row.ts` (00-as-row — 180 LOC)

**Tests existentes** (resumen): NINGUNO.

**Propuestas nuevas** (10):

1. **Render correcto de fila con datos de SQL query** — [webcomponent,sql-query]
   - **Setup**: mock `db.query` que retorna `[{id:1, label:'root', parent_id:null}]`; mount `<is-tree-row data-node-id="1">`.
   - **Acción**: esperar `connectedCallback` y micro-task flush.

2. **Migración desde formato plano a jerárquico falla si parent_id inválido** — [migration]
   - **Setup**: dataset con `{id:2, parent_id:99}` donde `99` no existe.
   - **Acción**: ejecutar `migrateFlatToTree(rows)`.
   - **Assertion**: lanza `MigrationError('orphan_parent:2->99')`; no retorna árbol parcial silencioso.

3. **Rollback al fallar mid-migration** — [migration,error-handling]
   - **Setup**: spy sobre la 5ª mutación para lanzar `Error('boom')`.
   - **Acción**: ejecutar migrate con try/catch y snapshot pre-migration.
   - **Assertion**: el estado del store queda idéntico al snapshot; rollback en orden inverso.

4. **Aria-expanded toggle en click** — [a11y,event]
   - **Setup**: row con `children.length > 0`; dispatch `click`.
   - **Acción**: leer `aria-expanded`.
   - **Assertion**: cambia `false → true`; emite `is-row-toggle` con `{id, expanded:true}`.

5. **Keyboard navigation: ArrowDown mueve foco al siguiente row visible** — [keyboard,a11y]
   - **Setup**: tree de 3 rows; foco en row 1.
   - **Acción**: dispatch `keydown` con `key='ArrowDown'`.
   - **Assertion**: `document.activeShadowRoot.activeElement` es row 2; row 1 pierde `tabindex=0`.

6. **SQL injection en `label` se escapa al renderizar** — [security,xss]
   - **Setup**: nodo con `label: "<img src=x onerror=alert(1)>"`.
   - **Acción**: mount.
   - **Assertion**: shadow DOM contiene `&lt;img src=x…` como texto; no se ejecuta el handler.

7. **`unmount()` limpia listeners para evitar memory leak** — [memory-leak,event]
   - **Setup**: spy `addEventListener`/`removeEventListener`; mount + unmount 100 veces.
   - **Acción**: contar listeners residuales vía `getEventListeners(elem)`.
   - **Assertion**: 0 listeners después de unmount; sin referencias circulares al store.

8. **Worker fetch inicial con retry exponencial en error de red** — [worker,error-handling]
   - **Setup**: mock `Worker.postMessage` que rechaza 2 veces y resuelve la 3ª.
   - **Acción**: invocar `loadInitialRows()`.
   - **Assertion**: se emiten 3 mensajes al worker con backoff 100ms, 200ms; payload final contiene `rows`.

9. **Migración batch con N>1000 usa chunking** — [performance,migration]
   - **Setup**: dataset de 5000 filas con ciclos válidos.
   - **Acción**: medir tiempo y memoria con `performance.memory` (Chromium).
   - **Assertion**: el procesamiento emite `progress` cada 500 filas; heap < 50MB; total < 2s en CI.

10. **`prefers-reduced-motion` desactiva animación de expand** — [reduced-motion,a11y]
    - **Setup**: `matchMedia('(prefers-reduced-motion: reduce)')` = true.
    - **Acción**: click en row con children.
    - **Assertion**: la animación CSS se salta (computed `animation-duration: 0s` o display inmediato sin `transition`).
