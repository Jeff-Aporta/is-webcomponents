## Gaps transversales recurrentes

1. **`prefers-reduced-motion` no respetado en todas las animaciones**: `inline-edit` (`ie-saved`/`ie-cancelled`), `input` (transitions del label flotante), `mention` (transitions), `pin-input` (`pin-shake`). Solo checkbox/radio/rating/slider/switch tienen media query dedicada. **Oportunidad**: helper `.is-anim` con clase que aplique `transition/animation: none` en `@media (prefers-reduced-motion: reduce)`.

2. **Visually-hidden input nativo (técnica `clip rect(0,0,0,0)`) repetido en `dropzone`, `file-input`, `pin-input`**: cada componente lo redefine a mano. **Oportunidad**: mixin CSS `@mixin sr-only` o shared stylesheet `_sr-only.css`.

3. **Color-mix con fallback hard-coded `transparent`**: muchos componentes (`checkbox`, `input`, `select`, `slider`, etc.) usan `color-mix(in srgb, var(--is-...) X%, transparent)` sin un fallback semántico (`var(--is-text-soft, #7a8390)`). En navegadores sin `color-mix` (Safari < 16.2) el `transparent` es literal — no degrada con elegancia. **Oportunidad**: helper o build step que genere fallback.

4. **Estados duplicados con atributo `[checked]` y `:state(checked)`**: en `checkbox`, `radio`, `switch` hay reglas duplicadas para ambos (líneas 117-120 de checkbox, 102-103 de radio, 158-159 de switch). Es defensivo (compatibilidad con State API), pero duplica trabajo de mantenimiento. **Oportunidad**: linter/stylelint rule que permita solo un set por archivo, con fallback documentado.

5. **Patrón `:host([variant=…])` con selectores encadenados que duplican background/border**: en `input`, `select`, `masked-input` la variante se aplica a `.base` y luego cada uno redefine border-radius/background independientemente. **Oportunidad**: tokens `--is-control-bg-filled`, `--is-control-bg-underlined` para que la variante cambie un solo token.

6. **Foco `:focus-visible` con outline `2px solid var(--is-focus)`**: aparece literalmente en `checkbox`, `color-picker`, `dropzone`, `file-input`, `input`, `masked-input`, `mention`, `select`. **Oportunidad**: clase `.is-focus-ring` global o design system token aplicado por un helper.

7. **`pointer-events: none` + `opacity: 0.55` para `[disabled]`**: copiado literal en casi todos los forms. **Oportunidad**: regla CSS única `[disabled] { opacity: 0.55; pointer-events: none; cursor: not-allowed }` en `is-base.min.css`.

8. **CDN loader: `inflight` Map y `jsDone` Map crecen sin garbage collection**: si una app carga 1000 tags distintos en sesión, las Maps nunca se purgan (ensure-element línea 9, loader línea 71). **Oportunidad**: TTL o LRU.

9. **CDN loader: `sendContext` usa `location.origin` como target de postMessage**: si el iframe termina siendo cross-origin (caso edge con `controlledShellSrc` si la app cambia de host), el `postMessage` falla silenciosamente sin error handler.

10. **`gallery/app.ts` parsea URL `?s=` con `JSON.parse(b64urlDecode(...))`**: si el base64url es válido pero el JSON dentro es `{ __proto__: { polluted: true } }` o similar, el `JSON.parse` es seguro pero la asignación posterior a `state` sí podría tener prototype pollution si se mergea con `Object.assign` (no es el caso aquí, pero el patrón es frágil — `Object.fromEntries` línea 467).

11. **No hay tests unitarios para CSS**: 15/20 testables son CSS puro. La estrategia de tests debe ser E2E (Playwright) con snapshot de `getComputedStyle` + assertions de tokens. No hay forma de testear CSS sin DOM.

## Notas para el runner de tests

- **Frontend (CSS)**: stack **Playwright** + `@playwright/test` para E2E. Page URL: `http://127.0.0.1:3080/<component>` o la galería `http://127.0.0.1:3080/`. Localizadores: piercing del shadow DOM (`page.locator('is-checkbox').locator('..')`) con `>>>` selectors (`is-checkbox >>> .control`). Timeouts: 5s para transiciones, 1s para assertions de computed style.
- **Backend TS (cdn)**: stack **Vitest** + jsdom o happy-dom. Para `customElements` stub se necesita `@web/test-runner` o `vi.stubGlobal('customElements', ...)`. Para `document.createElement('script')` mock con `vi.spyOn(document.head, 'appendChild')`. Timeouts: fake timers para `inflight` y `setTimeout`.
- **gallery/app.ts**: stack **Playwright** + emulación de viewport (480x800 para compact) y `localStorage` via `page.addInitScript`. Localizadores: `#brandMenu`, `.shell-nav__item[data-tag="…"]`, `#previewHost`. Timeouts: 2s para `showPreview` async.
- **code.preview.ts**: stack **Playwright** con localizadores específicos del preview (`#demo-lang`, `#pgCode`, etc.). Requiere que el preview shell esté mounted (la galería lo hace vía `loadPreview(tag)`).
- **Para prefers-reduced-motion**: `page.emulateMedia({ reducedMotion: 'reduce' })`.
- **Para CSS color-mix / vendor pseudo-elements**: usar Chromium (los `:has()`, `::-webkit-*`, `color-mix()` son Chromium-first; Firefox degrada partes).
