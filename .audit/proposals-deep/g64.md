## Gaps transversales recurrentes

1. **Pointer-events mixto en overlays**: `toast.css` (`pointer-events:none`
   en host, `auto` en slotted), `tooltip.css` (`auto` solo con `trigger=click`),
   `dropdown.css` (sin `pointer-events` en `.popup`, lo hereda del dialog).
   No hay contrato uniforme para "modal con click-through al fondo". **Oportunidad
   horizontal**: documentar y homogeneizar.

2. **Reduced-motion ausente en la mayoría de CSS**: solo `video.css` lo
   respeta explícitamente (L431-437). `progress-bar`, `avatar`, `callout`,
   `breadcrumbs` no declaran `prefers-reduced-motion`. **Oportunidad**:
   crear helper `_shared/reduced-motion.css` y aplicarlo.

3. **Fallback de tokens en cascada**: `var(--x, var(--y), fallback)` aparece
   en `callout.css`, `avatar.css`, `toast.css`, `video.css` con patrones
   distintos. **Oportunidad**: tipar/validar fallback chain.

4. **DnD sin a11y**: `kanban.ts` (drag HTML5 nativo), `transfer.ts`,
   `image-editor.ts` (selección con handles). **Oportunidad**: helper de
   teclado para mover elementos sin ratón.

5. **`@attr*` decorators**: `attrBool`/`attrStr`/`attrEnum`/`attrNum` están
   cubiertos por contrato pero no hay tests de **rendimiento** (1000 attr
   changes/sec). **Oportunidad**: bench.

6. **`materializarAtributos` y re-define**: `defineElement` es idempotente,
   pero `attrs.ts:206-220` no avisa si se redefine con attrs distintos.
   **Oportunidad**: warning explícito.

7. **Validación de inputs en CLI**: `run.ts` lee `E2E_BASE_URL` sin
   validar esquema (sólo `String(base)`). **Oportunidad**: validar `URL`
   constructor.

8. **`escapeHtml` ausente en data-grid**: `ag-grid.ts` lo importa (L90),
   pero `data-grid.ts` no lo hace en sus slots de filter popover.
   **Oportunidad**: auditar XSS en `data-grid` slots.

9. **Falta coverage E2E específica**: ni `ag-grid` ni `data-grid` tienen
   suite dedicada en `e2e/02-componentes.test.ts`. **Oportunidad**: crear
   `10-data-grid.test.ts` con smoke de sort/filter/edit.

10. **`stat.ts` acepta HTML en `value`**: el comentario L18 dice "admite
    formato HTML" pero sin escape. **Oportunidad**: validar o documentar
    riesgo XSS.

11. **`tooltip.css` sin keyboard navigation**: `pointer-events:auto` solo
    con `trigger="click"`; no hay `tabindex` ni escape. **Oportunidad**:
    documentar contrato trigger.

12. **No tests para `video.css`** (438 LOC, el más grande del grupo).
    **Oportunidad**: smoke E2E mínimo (play/pause/seek).

## Discrepancias de nomenclatura

**Importante**: los paths de tests listados en la consigna (líneas 50-89)
**no existen** en el proyecto. La suite real vive en `src/utils/testing/`
con subdirectorios `domain/`, `meta/`, `helpers/`, `e2e/` y nombres libres
(ej. `data-grid-toolbar.test.ts` está en `domain/`, no junto al source).
Esto es un gap **estructural**: los 40 testables no tienen `.test.ts`
adyacente, así que la cobertura solo se da via E2E (smoke) o contratos
(regex sobre fuente). El equipo debe decidir si:

1. Mover los tests a `*.test.ts` adyacentes al source (convención más
   común), o
2. Mantener la convención actual y mejorar la documentación del runner.

## Notas para el runner de tests

**Frontend (Playwright/Stagehand)**:
- Page URL: `http://127.0.0.1:3080/demos/index.html` (galería principal).
- Selectores: `is-{tag}` (custom element name), `[part="..."]` para CSS
  parts, `[data-*]` para state testing, `aria-*` para a11y.
- Snippet típico:
  ```ts
  test('modal-chrome: footer vacío no renderiza', async ({ page }) => {
    await page.goto('/demos/dialog.html');
    const el = page.locator('is-dialog:not([title])');
    await expect(el.locator('::part(footer)')).toHaveCSS('display', 'none');
  });
  ```
- Timeouts: 2s para conexiones de custom elements (`whenDefined`),
  5s para re-renders, 10s para tests E2E con servidor.

**CLI (Node.js test runner)**:
- Snippet típico:
  ```ts
  test('run.ts --only filtra archivos', async () => {
    const child = spawn('node', ['src/utils/testing/e2e/run.ts', '--only=button'], {
      env: { ...process.env, E2E_AUTOSERVE: '0', E2E_BASE_URL: 'http://x' },
    });
    const code = await new Promise((r) => child.on('exit', r));
    assert.equal(code, 0);
  });
  ```

**Contrato (regex sobre fuente)**:
- Patrón existente en `src/utils/testing/domain/data-grid-toolbar.test.ts`.
- Aplicable a los archivos CSS+TS del core (`element.ts`, `attrs.ts`)
  para verificar invariantes sin runtime.
