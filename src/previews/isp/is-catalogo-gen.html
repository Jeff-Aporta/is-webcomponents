<is-catalogo-gen>

Catálogo CRUD genérico (port de ISP CatalogoGen): toolbar, grilla y acciones Crear / Modificar / Verificar / Eliminar… según lo que exponga el controller.

Última acción: —

 
const cat = document.querySelector('is-catalogo-gen');
cat.controller = {
  entrie: 'Aplicación',
  primaryKeys: ['app'],
  columns: [
    { field: 'app', header: 'Aplicación' },
    { field: 'bactiva', header: 'Activa' },
  ],
  async Lista() { return { datos: [/* … */] }; },
  async actCrear(o) { return o; },
  async actModificar(o) { return o; },
  async actEliminar(o) { return o; },
  async actVerificar() {
    return { mensajes: [{ itdmensaje: 'info', mensaje: 'OK' }] };
  },
};
