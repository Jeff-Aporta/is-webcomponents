Charts

Motor de gráficos en SVG, sin dependencias externas. La configuración usa el mismo esquema de Chart.js, así que un config existente funciona sin cambios.

Cada tipo tiene su elemento (<is-bar-chart>, <is-line-chart>…) y además está <is-chart type="…">, que resuelve el tipo en tiempo de ejecución. Los colores salen de la paleta de marca activa y se revalidan al cambiar de tema: pruébalo con el selector de paleta del encabezado.

Configuración

Los datos entran por un <script type="application/json"> hijo o por la propiedad config. El esquema es el de Chart.js: { type, data: { labels, datasets }, options }.

Atributos

NombreValoresDescripción
typebar · line · pie · doughnut · radar · polarArea · scatter · bubbleSolo en <is-chart>; los elementos tipados lo fijan.
labeltextoTítulo sobre el gráfico.
x-label · y-labeltextoTítulos de eje.
index-axisx · yy produce barras horizontales.
stackedbooleanoApila las series.
gridauto · both · x · y · nonePor defecto solo el eje de valor.
min · maxnúmeroFija el dominio del eje de valor.
legend-positiontop · bottom · start · endUbicación de la leyenda.
without-legend · without-tooltip · without-animationbooleanoDesactivan cada parte.

Propiedades del dataset

NombreAplica aDescripción

backgroundColor · borderColortodosFuerzan el color; si faltan, se usa la paleta de marca.
tensionlineMayor que 0 dibuja curva suave.
steppedlineLínea escalonada.
filllineRellena el área bajo la línea.
borderRadiusbarRadio del extremo de la barra.
borderWidth · pointRadiusline · scatterGrosor del trazo y tamaño del punto.

Opciones

De config.options se leen scales.{x,y}.{min,max,stacked,beginAtZero,title.text}, plugins.legend.{display,position}, plugins.title.{display,text}, plugins.tooltip.enabled, indexAxis y cutout. Cuando un atributo del elemento y una opción definen lo mismo, gana el atributo.

Config por JavaScript

const el = document.querySelector('#jsChart');
el.config = {
  data: {
    labels: ['Q1', 'Q2', 'Q3', 'Q4'],
    datasets: [{ label: 'Ventas', data: [420, 580, 630, 710], tension: 0.4, fill: true }]
  }
};
