Referencia

<is-carousel>

AtributoTipoDefaultDescripción
activenumber0Slide activo (0-indexed).
loopbooleanfalseVuelve al inicio al llegar al final.
autoplaynumber (ms)0Avance automático (0 = desactivado).
verticalbooleanfalseOrientación vertical.
slides-per-pagenumber1Slides visibles por vista.
aspect-ratiostring16/9CSS aspect-ratio del contenedor.
without-controlsbooleanfalseOculta prev/next.
without-indicatorsbooleanfalseOculta los puntos.

API

carousel.next();        // Avanza
carousel.prev();        // Retrocede
carousel.pause();       // Pausa autoplay
carousel.play();        // Reanuda autoplay
carousel.active = 2;    // Salta a slide
carousel.getViewport(); // Devuelve el viewport del scroll

Eventos

EventoDescripción
is-carousel-changeCambia el slide. detail: { from, to, item }.
is-carousel-playComienza autoplay.
is-carousel-pausePausa autoplay. detail: { reason }.
is-carousel-slide-endTermina un swipe.
