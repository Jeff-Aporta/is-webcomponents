IsUi (módulo · no es un tag)

Utilidad de render para apps consumidoras. Tras cargar el CDN queda en globalThis.IsUi (alias Ui). No reinventes botones ni tablas: monta is-* con html + CSS hermano vía adoptCss.

IsUi.html

Plantilla etiquetada → DocumentFragment. Soporta valores, eventos y nodos hijos.

 
const { html } = IsUi;
host.append(html`
  <is-button color="brand" onclick=${() => IsUi.toast?.() || console.log('ok')}>
    Guardar
  </is-button>
`);

IsUi.define + adoptCss

Registra un custom element de dominio. El CSS va en archivo hermano (aquí se usa IsUi.css solo para el demo en página).

// demo-card registrado en esta página
app-* traduce datos → is-* 
import { html, adoptCss, define } from '…/helpers/ui.min.js';

class AppPanel extends HTMLElement {
  #root = this.attachShadow({ mode: 'open' });
  connectedCallback() {
    this.#root.append(html`<is-button color="brand">Acción</is-button>`);
    adoptCss(this.#root, import.meta.url); // → AppPanel.css hermano
  }
}
define('app-panel', AppPanel);
