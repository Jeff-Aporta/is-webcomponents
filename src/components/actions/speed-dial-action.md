# `<is-speed-dial-action>`

## Propósito

Acción hija de `<is-speed-dial>`. No se usa sola: vive dentro del speed dial y dispara su comando.

## Cuándo usarlo

Cuando el componente padre ya está en la pantalla y este tag es la pieza que le falta.

## Cuándo no usarlo

No lo reimplementes ni lo uses para sustituir al padre. La guía del padre documenta el conjunto.

## Ejemplo mínimo

```html
<is-speed-dial-action></is-speed-dial-action>
```
