# `<iswc-preview-controls>`

## Propósito

Panel de controles del playground. Aplica props de la definición JSON al ejemplo activo.

## Cuándo usarlo

Cuando el componente padre ya está en la pantalla y este tag es la pieza que le falta.

## Cuándo no usarlo

No lo reimplementes ni lo uses para sustituir al padre. La guía del padre documenta el conjunto.

## Ejemplo mínimo

```html
<iswc-preview-controls></iswc-preview-controls>
```
