# `<is-floating>` (interno)

Building block de posicionamiento anclado. **No es API pública.**

Usar siempre `<is-popover>` (o `<is-tooltip>`) en apps. Este tag solo existe
para consumo interno desde esos módulos.

No registres ni documentes `is-popup`: ese tag fue eliminado.
