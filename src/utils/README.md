# src/utils — ayudas de la galeria

Utilidades que usa la galeria y sus páginas. No son API del kit: son de la app.

## Piezas

- `home-cdn.ts` — de donde saca la galeria sus bundles (CDN o local).
- `cdn-sources.ts` — los orígenes posibles y su prioridad.
- `source-paths.ts` — las rutas de las fuentes (los `.ts` de cada componente).
- `section-schema.ts` — el esquema de las secciones de la pagina (`src/pages/*.json`).
