## Categorías

| Carpeta | Propósito |
| --- | --- |
| `actions` | Acciones, comandos, menús |
| `charts` | Series, distribuciones, jerarquías |
| `data` | Grid, stats, transfer, gauge, kanban |
| `data-viz` | Mapas/matrices; la mayoría de gráficas está en `charts/` |
| `diagrams` | Flujos, estados, ER, gantt, timeline… |
| `feedback` | Estado, progreso, toast, tag, skeleton |
| `forms` | Captura y validación |
| `helpers` | Formato, observers, popover |
| `isp` | Layout/forms portados de ISP-SvelteComponents |
| `layout` | Regiones, superficies, overlays de layout |
| `media` | Iconos, avatar, video |
| `navigation` | Tabs, tree, stepper, breadcrumb, carousel |
| `overlays` | Command palette, visor, ventanas flotantes |
