# src — el codigo del kit

| Ruta | Que es |
|---|---|
| `components/` | los componentes (`iswc-*`), cada uno en su carpeta |
| `core/` | las bases compartidas: `IswcReactive`, `IswcFormControl`, `IswcElement`, y los modulos comunes |
| `styles/` | los estilos: el kit (`kit/`), las paletas y los estilos globales |
| `cdn/` | el build del CDN: el loader por capas, el empaquetado y los scripts |
| `ai/` | las herramientas de IA (motores, descarga, vectores) |
| `utils/` | utilidades sin estado |
| `app/` | la aplicacion de la galeria |
| `pages/` | las paginas de la galeria |
| `previews/` | el armazon de los demos |
| `manifest.ts` | el catalogo de componentes (tag, categoria, version) |
| `manifest.schemas.ts` | los tipos del catalogo |

Cada carpeta tiene su `README.md` con lo que hay que saber antes de tocarla.
