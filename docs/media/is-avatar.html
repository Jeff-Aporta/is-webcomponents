Avatar

Avatar con imagen, iniciales o icono fallback. Caja = 1em × 1em; escala con font-size.

Formas

shape="circle" · square" · rounded" — el border-radius se aplica al contenedor.

imagen iniciales icono circle square rounded 
<span style="font-size:3rem">
  <is-avatar initials="AB" shape="rounded"></is-avatar>
</span>

Escala con font-size

Como la caja es 1em × 1em, basta con subir el font-size del padre.

Origen del contenido

Prioridad: image → initials → slot icon. Si la imagen falla al cargar, emite is-error y cae a initials.

Stack / group de avatares

Varios avatares juntos con margin-left negativo, como en chats o listas.

Icono fallback por slot

Sin imagen ni iniciales, el slot icon pinta cualquier <is-icon>.

Imagen rota

Si image falla y hay initials, el avatar cae a las iniciales automáticamente y emite is-error.

Referencia

Evento is-error al fallar la imagen. Sin size ni --size — usa font-size.
