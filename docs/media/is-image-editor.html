Image Editor

Canvas de edición con crop, zoom y rotación. Clic y arrastra el rectángulo para moverlo; las esquinas redimensionan.

API

const e = document.querySelector('is-image-editor');
e.zoom = 1.2;             // o e.applyZoom(0.1);
e.rotation = 90;           // grados, sentido horario
e.applyRotation(-90);

const out = e.cropped();  // dataURL image/png
e.image;                  // HTMLImageElement cargada

// Eventos
e.addEventListener('is-load',   e => ...);
e.addEventListener('is-change', e => /* crop rectangle cambia */);
e.addEventListener('is-crop',   e => /* resultado recortado listo */);

// Atributos
// src, zoom, rotation, aspect ("1", "4/3", "16/9" o "")
