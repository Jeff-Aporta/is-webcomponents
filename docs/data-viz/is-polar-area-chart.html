Polar Area Chart

Chart.js polarArea themed. Ángulos iguales por categoría; el radio refleja la magnitud (a diferencia de un pie, donde el tamaño es el ángulo). Ideal para comparar escalas en el mismo “reloj”.

Datos

JSON hijo application/json o propiedad config. El type queda fijo en polarArea.

<is-polar-area-chart label="Canales de tráfico">
  <script type="application/json">
    {
      "data": {
        "labels": ["Orgánico", "Directo", "Social", "Email", "Paid"],
        "datasets": [{ "label": "Sesiones", "data": [4200, 3100, 1800, 950, 2400] }]
      }
    }
  </script>
</is-polar-area-chart>

Opciones

Misma API de presentación que is-chart: leyenda, animación, título.

legend-position="end"
without-legend
without-animation
<is-polar-area-chart legend-position="end" label="NPS">…</is-polar-area-chart>
<is-polar-area-chart without-legend>…</is-polar-area-chart>
<is-polar-area-chart without-animation>…</is-polar-area-chart>

Tema · CSS variables

Colores por sector vía --fill-color-1..6 y --border-color-1..6 en el host (o un ancestro).

is-polar-area-chart.mi-tema {
  --fill-color-1: color-mix(in srgb, #38bdf8 72%, transparent);
  --fill-color-2: color-mix(in srgb, #a78bfa 72%, transparent);
  --border-color-1: #38bdf8;
  --border-color-2: #a78bfa;
}
