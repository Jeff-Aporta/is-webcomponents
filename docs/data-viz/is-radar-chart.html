Radar Chart

<is-radar-chart>

Compara varias variables a la vez sobre una rejilla radial. Ideal para perfiles (habilidades, atributos de producto, métricas de rendimiento).

Datos con JSON

Coloca un <script type="application/json"> hijo. Cada valor de data mapea a una etiqueta del eje radial (formato Chart.js).

<is-radar-chart label="Feature Comparison">
  <script type="application/json">
    {
      "data": {
        "labels": ["Speed", "Reliability", "Ease of Use", "Features", "Support"],
        "datasets": [{ "label": "Product A", "data": [85, 90, 75, 80, 70], "fill": true }]
      }
    }
  </script>
</is-radar-chart>

Datos con JavaScript

Asigna config; el chart se re-renderiza solo.

const chart = document.querySelector('#radarJs');
chart.config = {
  data: {
    labels: ['Speed', 'Reliability', 'Ease of Use', 'Features', 'Support'],
    datasets: [{ label: 'Product A', data: [85, 90, 75, 80, 70], fill: true }],
  },
};

Múltiples datasets

Superpone perfiles para compararlos directamente.

chart.config = {
  data: {
    labels: ['Speed', 'Reliability', 'Ease of Use', 'Features', 'Support', 'Value'],
    datasets: [
      { label: 'Nimbus', data: [85, 90, 75, 80, 70, 88], fill: true },
      { label: 'Atlas', data: [70, 80, 90, 85, 92, 75], fill: true },
    ],
  },
};
