Catálogo Gen

Catálogo CRUD genérico ISP con controller JSON.

Catálogo CRUD (port ISP CatalogoGen). El controller se genera con createCatalogController(json): listado, columnas y acciones (crear / modificar / visualizar / verificar / duplicar / recodificar / eliminar / consolidar).

Selecciona una fila: la toolbar habilita acciones que requieren selección sin parpadear (el grid pinta la selección in-place). En demos se usa mock; en producción pasa server + endpoints.

Última acción: —

import { createCatalogController } from './isp/controller-from-config.min.js';

cat.controller = createCatalogController({
  entrie: 'Curso',
  primaryKeys: ['icurso'],
  columns: [
    { field: 'icurso', header: 'Código' },
    { field: 'ncurso', header: 'Nombre' },
  ],
  // actions: true  → todas (default)
  // actions: ['crear','modificar','eliminar']
  mock: [
    { icurso: 'C001', ncurso: 'Contabilidad básica' },
  ],
  // server: {
  //   useLocal: false,
  //   local:  { host: 'localhost', port: 20040, https: false },
  //   remote: { host: '….azurewebsites.net', port: 443, https: true },
  // },
  // endpoints: { recurso: 'curso', recursos: 'cursos' },
  // token: () => sessionStorage.getItem('token'),
});
