Btn Ref

Campo + modal de selección ISP (BtnRef).

Campo con selector modal (port BtnRef). El modal usa <is-catalogo-gen select-mode> centrado. Controller vía createBtnRefController — sin acciones CRUD, solo listado y selección.

Seleccionado: —

import { createBtnRefController } from './isp/controller-from-config.min.js';

el.controller = createBtnRefController({
  entrie: 'Aplicación',
  primaryKeys: ['app'],
  ColumnsBtnRef: ['app'],
  columns: [{ field: 'app', header: 'Aplicación' }],
  mock: [{ app: 'ContaPyme' }, { app: 'AgroWin' }],
});

Multi-select

Atributo multi (o multiSelect: true en el JSON). El modal permite marcar varias filas; al confirmar se aplica el registro elegido (último / pick).

Seleccionado: —

<is-btn-ref label="Apps" multi></is-btn-ref>

createBtnRefController({ …, multiSelect: true, mock: […] });
