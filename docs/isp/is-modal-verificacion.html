Modal Verificación

Documentación y demos de is-modal-verificacion de InSoft.

Al abrirse ejecuta controller.actVerificar(record) y pinta los mensajes devueltos coloreados por severidad, con contadores de infos, warnings y errores.

Verificar tercero 
const modal = document.querySelector('is-modal-verificacion');
modal.controller = {
  entrie: 'tercero',
  async actVerificar(record) {
    return { mensajes: [
      { itdmensaje: 'info', mensaje: 'NIT válido.' },
      { itdmensaje: 'warning', mensaje: 'Sin correo registrado.' },
    ] };
  },
};
modal.record = { nit: '900123456' };
modal.show();

API rápida

Propiedades JS: controller, record, onError. Métodos: show(), hide(), verify().
