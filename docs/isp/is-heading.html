CSS libre y current


Si no es semántico, color es un color CSS. current hereda el color tipográfico del contexto.



            

              current (hereda azul del padre)
              
color="current"

            

            

              Naranja CSS
              
color="#e8590c"

            

            

              oklch sin mix
              
color="oklch(…)" · mix="0%"

            

            

              50% transparent
              
mix="50%" · mix-with="transparent"

            

          






mix


Prop mix (antes style="--h-mix"). Porcentaje de
          --is-text mezclado sobre el acento.



            

              Sin override
              
sin mix · (default mix)

            

            

              Solo acento
              
mix="0%" · sin mezcla con texto

            

            

              Mitad
              
mix="50%"

            

            

              Todo texto
              
mix="100%" · color de texto

            

          


<is-heading level="2">(default mix)</is-heading>
<is-heading level="2" mix="0%">Solo acento</is-heading>
<is-heading level="2" mix="100%">Todo texto</is-heading>
