Ficha ISP — cuerpo en JSON compacto (json2html / html2json).

Ficha con Aceptar / Cancelar. El cuerpo se define en JSON compacto ([tag, attrs?, …hijos]) vía json2html / html2json.

Lenguaje de definición = JSON. En BD se guarda el HTML como JSON; en runtime: form.fromJSON({ body, values }).
html2json / toJSON setValues(demo) 

          
Última acción: —


form.fromJSON({
  mode: 'edit',
  body: [
    ['h3', { slot: 'header' }, 'Curso'],
    ['div', { slot: 'content', style: 'display:flex;flex-direction:column;gap:0.75rem;padding:0.5rem' },
      ['is-input', { name: 'icurso', label: 'Código', required: true, 'full-width': true }],
      ['is-input', { name: 'ncurso', label: 'Nombre', 'full-width': true }],
      ['is-switch', { name: 'activo' }, 'Activo'],
    ],
  ],
  values: { icurso: 'C001', ncurso: 'Nómina', activo: true },
});

form.html2json(); // solo el light DOM
form.toJSON();    // chrome + body + values
