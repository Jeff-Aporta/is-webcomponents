Loading Overlay

Documentación y demos de is-loading-overlay de InSoft.

Capa de bloqueo a pantalla completa con spinner y mensaje. No se cierra con Escape ni con clic fuera: solo el código que la abrió la cierra.

Simular guardado (2 s) 
<is-loading-overlay open message="Guardando…" scroll-lock></is-loading-overlay>

Indicador propio

El slot por defecto reemplaza al <is-spinner>.

Ver con icono 
<is-loading-overlay message="Consolidando…">
  <is-icon icon="mdi:database-sync"></is-icon>
</is-loading-overlay>

Abrir y cerrar desde código

Cierra siempre en un finally: si la promesa falla y nadie la cierra, la aplicación queda bloqueada.

const ov = document.querySelector('is-loading-overlay');
ov.show();
try { await guardar(); } finally { ov.hide(); }
