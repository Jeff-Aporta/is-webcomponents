Context Menu

Menú anclado al clic derecho sobre un elemento. Compatible con cualquier árbol DOM: target por selector.

Básico

Por defecto el menú se cierra al hacer scroll (no persigue el viewport). Con scroll-lock bloquea el scroll del documento mientras está abierto.

Clic derecho aquí →

scroll-lock

Menú importante: el atributo scroll-lock congela el documento hasta cerrar (Escape, clic fuera o elegir ítem).

Clic derecho (scroll bloqueado) →
<is-context-menu for="#canvas" scroll-lock>
  <button class="item" data-value="ok">Confirmar</button>
</is-context-menu>

Sobre varios ítems

Aplica el mismo context-menu a cada fila del listado. El menú sabe qué fila disparó.

API

const menu = document.querySelector('is-context-menu');
menu.openAt(x, y);
menu.close();
menu.isOpen;
menu.scrollLock = true; // opcional: bloquear scroll en vez de cerrar

menu.addEventListener('is-select', e => {
  console.log('elegido:', e.detail.value);
});

// Default: cierra al scroll. Importante: scroll-lock.
<is-context-menu for="#canvas">…</is-context-menu>
<is-context-menu for="#canvas" scroll-lock>…</is-context-menu>
