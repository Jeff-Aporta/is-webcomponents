Radial

direction="radial" reparte las acciones en un abanico alrededor del trigger. El ángulo inicial y la amplitud del arco se calculan según el espacio libre dentro del contenedor, y cuando el arco no alcanza para todas las acciones se abren anillos concéntricos con los elementos desfasados medio paso (distribución en panal).

Pega el dial contra una esquina y el abanico se recorta y se gira solo hacia donde hay sitio: 

<is-speed-dial direction="radial" data-arc="180" data-start-angle="-90"
               data-sweep="counter-clockwise" data-wrapper=".mi-lienzo">
  <is-speed-dial-action icon="mdi:brush" label="Tema"></is-speed-dial-action>
</is-speed-dial>

API

const dial = document.querySelector('is-speed-dial');
dial.open();         // abre
dial.close();        // cierra
dial.toggle();       // alterna
dial.isOpen;         // boolean
dial.addEventListener('is-select', e => console.log(e.detail.action.getAttribute('label')));
dial.addEventListener('is-toggle', e => console.log('open=', e.detail.open));

// Acciones: cada <is-speed-dial-action> emite is-select en el padre.
// Si tiene href, no se cierra el dial al elegir.
<is-speed-dial-action icon="…" label="…" color="brand|neutral|success|warning|danger" href="…">Texto</is-speed-dial-action>
