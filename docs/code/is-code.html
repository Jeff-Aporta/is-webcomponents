Code

Editor de código (CodeMirror 5) con lenguajes, temas JSON, formateo estilo Prettier, números de línea, word-wrap y anotaciones externas (highlight / tooltips). API texto ↔ JSON is-code-doc/v1.

<is-code lang="javascript" wrap line-numbers
  value="function greet(name) {\n  return `Hola, ${name}`;\n}"></is-code>

Modos block / inline

mode="block" (default) ocupa el ancho del contenedor. mode="inline" fluye en el texto como un chip editable — ideal para inserts en docs o labels.

Usa para disparar el diálogo, o edita en vivo. 

<p>Llama <is-code mode="inline" lang="js" readonly value="save()"></is-code> al guardar.</p>
<is-code mode="block" lang="javascript" wrap></is-code>

Diff y resumen de commit

lang="diff" y lang="commit" comparten un modo propio del kit. Pintar un diff con un modo de lenguaje sale mal siempre: el + de la primera columna no es código, es una marca de línea, y un tokenizador de JS lo lee como operador y descoloca el resto. Aquí se clasifica por línea entera, con banda de fondo en las que entran y salen. format() no re-indenta nada — solo alinea la rejilla del --stat.

format() — alinear rejilla 
<is-code lang="diff" readonly line-numbers
  value="@@ -1,2 +1,3 @@\n-const a = 0;\n+const a = 1;"></is-code>

<!-- format() alinea ruta | contador | barra del --stat -->
<is-code lang="commit" value="src/app.js | 12 ++++----"></is-code>

Formateo (JSON tipo Prettier)

Atributo/propiedad format / formatConfig. Método format().

Format 
<is-code lang="javascript"
  format='{"tabWidth":2,"singleQuote":true,"semi":true}'></is-code>

<script type="module">
  editor.format();
</script>

Temas JSON

Sin config: preset según data-theme. Con theme-config: colores por rol (keyword, string, gutter, marks…).

Ocean Reset preset 
<is-code lang="css"
  theme-config='{"background":"#0b1220","keyword":"#7dd3fc","string":"#86efac"}'></is-code>

Highlights y tooltips

El editor no diagnostica: otro sistema aporta marks (error/warning/info o tooltip de docs). Se reutiliza <is-tooltip>.

editor.setMarks([
  { from: 9, to: 12, kind: 'tooltip', title: 'add()', body: 'Suma a + b' },
  { from: 26, to: 27, kind: 'highlight', tone: 'warning', message: 'Prefer const' },
]);

code2json / json2code

Documento is-code-doc/v1: value + marks + format + theme. Round-trip con getDocument() / setDocument().

code → json json → code 
(pulsa code → json)
const doc = editor.code2json();
editor.setDocument(doc);
