Org Chart

Organigrama jerárquico a partir de un árbol JSON. Cada nodo tiene foto (o iniciales), nombre y cargo; los hijos se pliegan con el botón redondo con una animación suave, y un clic en el fondo abre el visor a pantalla completa.

Familia Buendía (Macondo)

Ejemplo más grande — inspirado en Cien años de soledad — para probar el plegado con varios niveles de profundidad y anchura. Pasa el cursor sobre una tarjeta para ver su detail; clic en el fondo abre <is-diagram-lightbox> (atributo open-on-click).

API

// Datos (script hijo o propiedad `payload`)
// [
//   { id, title, name, parent, photo?, detail?|tooltip? },
//   ...
// ]

const org = document.querySelector('is-org-chart');
org.collapse(id); // o .expand(id) / .toggle(id)
org.payload = [...]; // alternativa al <script type="application/json">

org.addEventListener('is-select', e => console.log(e.detail.id, e.detail.node));
org.addEventListener('is-toggle', e => console.log('toggle', e.detail.id, 'collapsed=', e.detail.collapsed));
org.addEventListener('is-open-viewer', e => console.log('abrir visor', e.detail.payload));

// Atributos
// direction       down (default) | up | right
// node-width      default 200
// node-height     default 78
// gap             default 28
// open-on-click   clic en el fondo abre <is-diagram-lightbox kind="org-chart">
// detail / tooltip (por nodo)   texto que aparece al pasar el cursor sobre la tarjeta
