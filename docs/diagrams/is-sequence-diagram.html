Diagrama de secuencia

Diagrama de secuencia en SVG, sin Mermaid. La configuración es un JSON con actores, mensajes y grupos; el layout (posiciones, ruteo ortogonal de las flechas y colocación de etiquetas) se calcula solo.

Haz clic en el diagrama para abrir el visor a pantalla completa, con controles de la animación tortuga, tooltips por paso y leyenda de grupos que puedes encender y apagar.

json

Configuración por JSON

Mismo esquema del proyecto original. actors define las lifelines, messages los pasos y groups el color por tono HSL (0–360).

alt

Ramas alt

Con alt.branches el diagrama encierra los pasos condicionales en una caja punteada y rotula cada rama.

viewer

Visor a pantalla completa

El visor se abre solo al hacer clic. También puedes montarlo tú mismo con <is-diagram-lightbox> y controlarlo por propiedades.
