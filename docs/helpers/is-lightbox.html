Lightbox

Visor a pantalla completa, genérico: lo que metas en el slot default se monta dentro de un <dialog> top-layer con zoom anclado al cursor y pan. Por defecto usa variant="backdrop" (20% oscuro + blur 2px). La barra por defecto trae cerrar, reset de zoom y compartir enlace; usa el slot toolbar para añadir tus propios controles sin tocar el componente.

<!-- default: backdrop 20% + blur 2px -->
<is-lightbox id="lb">…</is-lightbox>

<!-- lienzo opaco a pantalla completa -->
<is-lightbox variant="solid">…</is-lightbox>

Variantes de backdrop

backdrop (default) deja ver la página con oscuridad 20% y blur 2px. solid pinta el dialog opaco como antes.

Backdrop

Página visible detrás · rgb(0 0 0 / 20%) + blur(2px).

Solid

Lienzo opaco a pantalla completa (sin ver la página).

<is-lightbox>…</is-lightbox>
<is-lightbox variant="solid">…</is-lightbox>

Galería con contenido propio

Cada tarjeta es contenido que el visor recibe como slot. Distintos tipos (svg, html, video) comparten la misma API.

Toolbar personalizada (slot)

Si pones algo en el slot toolbar, esos elementos aparecen en la cabecera y los botones por defecto que ya no aportan (zoom-in/out/reset y share) se ocultan automáticamente. 

<is-lightbox>
  <div slot="toolbar">
    <button>Rotar</button>
    <button>Descargar</button>
  </div>
  <svg>…</svg>
</is-lightbox>

Contenido vivo: video

Si el contenido es interactivo (video, mapa, canvas) el visor lo monta sin más. El zoom + pan se aplica sobre el envoltorio, no sobre el medio, así que el video sigue siendo operable.

Referencia

El antiguo <is-diagram-lightbox> es ahora una variante de este lightbox con la toolbar de la animación tortuga (play/pause/prev/next/ring), el editor de código JSON y el enlace compartible con el payload del diagrama codificado en ?d=.
