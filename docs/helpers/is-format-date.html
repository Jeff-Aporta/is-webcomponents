Locales (Intl nativo)

Se filtran con Intl.DateTimeFormat.supportedLocalesOf(). Cada tarjeta muestra el ahora en ese locale (con segundos).

Cargando locales…

<is-format-date
  locale="ja"
  weekday="long" month="long" day="numeric" year="numeric"
  hour="numeric" minute="numeric" second="numeric"
></is-format-date>
<!-- en el preview, date se reescribe cada 1s con Date.now() -->
