Observer

Un solo componente para IntersectionObserver, MutationObserver y ResizeObserver vía type. Los alias históricos (<is-intersection-observer>, etc.) siguen válidos.

El host usa display: contents: no ocupa caja propia. Los hijos directos son lo observado (intersection / resize) o el subárbol a vigilar (mutation).
  • intersection — ¿está visible en el viewport / un scroller?
  • mutation — ¿cambió el DOM (hijos / atributos / texto)?
  • resize — ¿cambió el tamaño del hijo?

type="intersection"

Haz scroll en el panel. Las tarjetas arrancan atenuadas; al entrar (≥ 40 % visible) reciben is-in, se iluminan y el badge pasa a «en vista».

root = #obsScroller · threshold = 0.4 · intersect-class = is-in

type="mutation"

El nodo de la izquierda es el subárbol observado. Cada botón dispara una mutación concreta; el log muestra is-mutate.

child-list + attr="data-tag"
Nodo observado
Contenido editable
Añadir hijo Cambiar data-tag Reset

Pulsa un botón para mutar el DOM y ver el evento.

Las mutaciones aparecen aquí.
<is-observer type="mutation" attr="data-tag" child-list>
  <div id="target" data-tag="init">…</div>
</is-observer>

type="resize"

Arrastra la esquina inferior derecha del cuadro (CSS resize: both). El tamaño en vivo y el log se actualizan con is-resize.
