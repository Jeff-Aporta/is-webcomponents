Resize Observer

Observa hijos directos y emite is-resize con las ResizeObserverEntry. Alias de <is-observer type="resize">.

Arrastra la esquina ↘ del cuadro. El tamaño en vivo y el log se actualizan con cada is-resize.
resize: both · overflow: auto
Arrastra la esquina ↘ para redimensionar.
Tamaño: — × — activo
Los eventos is-resize aparecen aquí.
<is-resize-observer>
  <div style="resize:both; overflow:auto">…</div>
</is-resize-observer>

el.addEventListener('is-resize', (e) => {
  const entry = e.detail.entries[0];
  console.log(entry.contentRect.width, entry.contentRect.height);
});

disabled

Con disabled el observer se desconecta: redimensionar ya no emite eventos. El botón alterna el atributo y su propia etiqueta.

Desactivar observer activo
Panel secundario — redimensiona con el observer ON/OFF.
Tamaño: — × —
Solo registra mientras el observer esté activo.
<is-resize-observer disabled>…</is-resize-observer>
// o en runtime:
el.toggleAttribute('disabled');
