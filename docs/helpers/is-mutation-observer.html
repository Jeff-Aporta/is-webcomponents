Observador de mutación

Responde a: ¿cambió el HTML de este nodo? Cuando alguien añade/quita hijos, cambia un atributo o el texto, emite is-mutate con el detalle de qué pasó.

No es Intersection Observer. Aquel mira visibilidad (¿está en pantalla?). Este mira estructura (¿se modificó el DOM?). Útil para reaccionar a cambios de terceros, sincronizar UI, o depurar qué muta un widget.
  • child-list — entra o sale un nodo hijo (appendChild, remove…).
  • attr — cambia un atributo filtrado (aquí solo data-x).
  • character-data — cambia el texto de un nodo (opcional; no activo en este demo).
