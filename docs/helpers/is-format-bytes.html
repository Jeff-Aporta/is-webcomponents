Formato de bytes

Autofit · unidad ≥ 1

Con autofit se elige la unidad más alta cuyo valor sea al menos 1. 204800 → 200 KB (no 0.2 MB); desde 1 MiB sí MB.

autofit · 204800 B
autofit · 1 MiB
autofit · 512 B 
<is-format-bytes autofit value="204800"></is-format-bytes>
<is-format-bytes autofit value="1048576"></is-format-bytes>

Locale · mismo valor, distinto resultado

Mismo tamaño (1 536 000 bytes ≈ 1,5 MB). Cambia el separador decimal (. vs ,), la unidad (MB / Mo / م.ب / メガバイト) y, con display="long", el nombre completo traducido.

value="1536000" · short
en → 1.5 MB
es → 1,5 MB
fr → 1,5 Mo
