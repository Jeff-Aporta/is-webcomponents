API HTTP vs actions

Prioridad: actions (callbacks JS) → api/src (fetch) → solo eventos locales. Tipos en md-editor-api.d.ts.

// A) Custom actions (sin app URL)
el.actions = {
  load: async () => ({ content: await store.get('doc'), filename: 'doc.md' }),
  persist: async (doc) => { await store.put(doc); return doc; },
};
await el.load();

// B) Endpoints HTTP
el.api = {
  baseUrl: 'https://api.ejemplo.com',
  endpoints: { get: '/docs/1', put: '/docs/1' },
  token: () => localStorage.getItem('token'),
};
await el.load();

// Atajo GET:
// <is-md-editor src="/api/docs/1" can-edit></is-md-editor>
