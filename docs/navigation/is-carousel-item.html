Referencia

<is-carousel> + <is-carousel-item> — Web Components (vanilla, zero dependencies). Carrusel tipo slides con paginación, autoplay, loop, navegación prev/next, indicadores y soporte para swipe en touch. <is-carousel autoplay loop> <is-carousel-item>…</is-carousel-item> <is-carousel-item>…</is-carousel-item> <is-carousel-item>…</is-carousel-item> </is-carousel> Atributos <is-carousel> active number (0-indexed) loop boolean (default false) autoplay number (ms) (default 0 — desactivado) without-controls boolean (oculta prev/next) without-indicators boolean (oculta indicators) vertical boolean (slides verticales) slides-per-page number (default 1) aspect-ratio string (CSS, e.g. "16/9") Atributos <is-carousel-item> label string (accesibilidad) disabled boolean Slots <is-carousel> (default) items. prev-icon override del icono prev. next-icon override del icono next. <is-carousel-item> (default) contenido del slide. Eventos is-carousel-change detail: { from, to, item } is-carousel-pause detail: { reason: 'user' | 'auto' | 'visibility' } is-carousel-play detail: {} is-carousel-slide-end (cuando termina swipe) CSS Parts is-carousel: ::part(base) ::part(viewport) ::part(track) ::part(indicators) ::part(controls) is-carousel-item: ::part(base)
