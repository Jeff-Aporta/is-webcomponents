PDF Viewer

Visor de PDF. Por defecto delega en el visor nativo del navegador (<iframe type="application/pdf">) — sin dependencias, sin peso adicional.

Demo

Documento de ejemplo abrir en pestaña ↗

API

const v = document.querySelector('is-pdf-viewer');
v.src = '/files/manual.pdf';
v.currentPage;  // número de página actual (iframe + #page=N)

// Eventos
v.addEventListener('is-load',  () => /* listo */);
v.addEventListener('is-error', () => /* error de carga */);

// Slots
//   title       texto de la izquierda
//   toolbar     contenido extra a la derecha

// Atributos
// src           URL del PDF (requerido)
// engine        native (default) | pdfjs
// height        alto del iframe
// download      boolean — botón Descargar
// print         boolean — botón Imprimir
// page, zoom    sólo con engine=pdfjs (cuando integres pdfjs en tu build)
