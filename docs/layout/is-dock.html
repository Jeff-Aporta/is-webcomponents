Dock

Barra tipo macOS: los íconos se magnifican al acercar el cursor. Anclada abajo por defecto; podés moverla con el atributo position.

Inferior

Lateral izquierdo

API

// Cambia el ítem activo programáticamente
document.querySelector('is-dock-item[label="Inicio"]').setAttribute('active', '');

// Escucha selección
dock.addEventListener('is-select', e => console.log(e.detail.item.getAttribute('label')));

// Atributos
// position    bottom (default) | top | left | right
// max-scale   factor máximo (default 1.6)
// range       píxeles de alcance (default 110)

<is-dock-item label="…" icon="mdi:…" href="…" active />
