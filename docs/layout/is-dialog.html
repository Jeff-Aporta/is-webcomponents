Dialog

Documentación y demos del componente is-dialog de InSoft.

Modal accesible que requiere la atención inmediata del usuario. Equivalente a <dialog> nativo, con header, footer, animaciones, light-dismiss y API declarativa data-dialog="close".

Abrir diálogo

Esto es un diálogo estándar. Puedes poner cualquier contenido aquí.

Cancelar Aceptar 
<is-button onclick="document.getElementById('dlg').open = true">Abrir</is-button>
<is-dialog id="dlg" label="Título">
  Contenido.
  <div slot="footer">
    <is-button data-dialog="close">Cancelar</is-button>
  </div>
</is-dialog>

without-header oculta el header y el botón de cerrar.

Ancho

Define --width en el host para cambiar el ancho preferido. Se reduce automáticamente en pantallas pequeñas.

Diálogo ancho

Este diálogo es más ancho que el predeterminado, útil cuando necesitas más espacio para el contenido.

Entendido 
<is-dialog style="--width: 800px">…</is-dialog>

Light dismiss

Abrir (click fuera cierra)

Haz click fuera del diálogo para cerrarlo.

<is-dialog light-dismiss>…</is-dialog>

Prevenir el cierre

Cancela el evento is-hide con event.preventDefault() para impedir el cierre. Si el usuario intenta cerrar, el diálogo pulsa brevemente para llamar la atención.

Diálogo protegido

Este diálogo solo se cierra con el botón "Guardar y salir". Si cierras con Escape o el botón X, el diálogo pulsa brevemente.

Guardar y salir 
dialog.addEventListener('is-hide', (e) => {
  if (e.detail.source !== closeButton) e.preventDefault();
});
