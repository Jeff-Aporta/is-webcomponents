Apariencias

El atributo appearance ajusta el fondo y borde. Default: outlined.

Borde 1px, fondo transparente. Fondo elevado, sin borde. Fondo + borde. Sin fondo ni borde, solo espaciado. 
<is-details variant="filled" summary="…">…</is-details>

Posición del icono

icon-placement: start o end. Default: end.

Contenido que se revela al hacer click. El chevron rota 180° al expandir y se ubica a la izquierda. 
<is-details icon-placement="start" summary="…">…</is-details>

Iconos custom

Slots expand-icon y collapse-icon para reemplazar el chevron por defecto.

Al expandirse se muestra un signo menos; al colapsarse, un más. Cambia el icono según el estado. 
<is-details summary="…">
  <is-icon slot="expand-icon" icon="mdi:plus"></is-icon>
  <is-icon slot="collapse-icon" icon="mdi:minus"></is-icon>
  Contenido…
</is-details>

Summary rico (slot)

En lugar del atributo summary, usa el slot summary para contenido rico (iconos, badges, etc.).

Pedido #A-10293 Enviado
Cliente: Distribuidora del Norte · Total: $1.245,00 · 3 ítems. 
<is-details>
  <div slot="summary">
    <strong>Pedido #A-10293</strong>
    <is-badge color="success">Enviado</is-badge>
  </div>
  Cliente: …
</is-details>

Estados

open para abrir por defecto; disabled bloquea la interacción.

El atributo open lo deja expandido desde el primer render. El atributo disabled desactiva el toggle. 
<is-details open summary="…">…</is-details>
<is-details disabled summary="…">…</is-details>

API JavaScript

Métodos: show(), hide(), toggle(). Propiedades: open, summary, name.

Esto lo abro y cierro desde los botones de abajo.
show() hide() toggle() 
<is-details id="apiDetails" summary="Demo">…</is-details>
<script>
  document.getElementById('btnOpen').onclick  = () => document.getElementById('apiDetails').show();
  document.getElementById('btnClose').onclick = () => document.getElementById('apiDetails').hide();
  document.getElementById('btnToggle').onclick = () => document.getElementById('apiDetails').toggle();
</script>

Eventos

Burbujean y son composed: true: is-show, is-after-show, is-hide, is-after-hide.

El evento is-after-show se dispara tras la animación de apertura.
Log:
document.getElementById('evtDetails').addEventListener('is-after-show', () => {
  console.log('abierto');
});
