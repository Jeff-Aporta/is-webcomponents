Panel dividido

Documentación y demos del componente is-split-panel de InSoft.

Dos paneles adyacentes separados por un divisor arrastrable. Componente InSoft accesible, escrito en JavaScript nativo con Shadow DOM, sin frameworks.

Persistencia: con storage-key="mi-panel" el tamaño se guarda en localStorage['is-webcomponents'] como JSON compartido por todos los WC: { "is-split-panel": { "mi-panel": { "positionInPixels": 240 } } }. Sin storage-key no escribe nada.

Primary end

Con primary="end" el panel final mantiene su tamaño cuando el host cambia de dimensión; el inicial crece/se encoge. Por defecto (primary="start") es al revés.

Teclado

Foco en el divisor (Tab) y luego: ←/→ mueve 1%, Shift ×10. Home/End salta a los extremos. Enter colapsa y restaura el panel primario.
