Toast

Contenedor fijo de notificaciones. Crea ítems con create() o declara <is-toast-item>.

brand success warning danger sticky (duration 0) 
const toaster = document.getElementById('toaster');

document.getElementById('btn-brand').addEventListener('click', () => {
  toaster.create('Mensaje brand', { variant: 'brand' });
});
document.getElementById('btn-success').addEventListener('click', () => {
  toaster.create('Operación correcta', { variant: 'success' });
});
document.getElementById('btn-warning').addEventListener('click', () => {
  toaster.create('Revisa los datos', { variant: 'warning' });
});
document.getElementById('btn-danger').addEventListener('click', () => {
  toaster.create('Error al guardar', { variant: 'danger' });
});
document.getElementById('btn-sticky').addEventListener('click', () => {
  toaster.create('Quédate hasta cerrar', { variant: 'neutral', duration: 0 });
});

Placement

Seis anclas: top|bottom × start|center|end (logical; en LTR start=izquierda, end=derecha).

top-start top-center top-end bottom-start bottom-center bottom-end 
const toaster = document.getElementById('toaster');

document.querySelectorAll('[data-place]').forEach((btn) => {
  btn.addEventListener('click', () => {
    const placement = btn.dataset.place; // top-start | top-center | …
    toaster.placement = placement;
    toaster.create(placement, { variant: 'brand' });
  });
});

Promise

toaster.promise(p, { loading, success, error }) muestra un toast loading con spinner y lo actualiza en sitio al resolver o rechazar. Cada callback acepta string, función o { message, options }.

Simular éxito Simular error Mensaje dinámico 
// success/error como string
toaster.promise(guardar(), {
  loading: 'Guardando…',
  success: 'Guardado',
  error: 'No se pudo guardar',
});

// success como función que recibe data / error que recibe err
toaster.promise(cargarFilas(), {
  loading: 'Cargando filas…',
  success: (data) => `${data.total} filas cargadas`,
  error: (err) => `Falló: ${err.message}`,
});
