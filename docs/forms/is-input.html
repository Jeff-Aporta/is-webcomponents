Input

Campo de texto form-associated con paridad funcional con el TextField de MUI: tres appearances, estado de error ligado a la validación nativa, adornos, contador de caracteres y ancho controlable. Participa en <form> vía ElementInternals.

value: ""

Appearance

appearance equivale a las variants de MUI: outlined (default) · filled · underlined (el standard de MUI).

<is-input label="outlined (default)"></is-input>
<is-input variant="filled" label="filled"></is-input>
<is-input variant="underlined" label="underlined"></is-input>

Tipos

type pasa al input nativo interno junto con min, max, step, maxlength y autocomplete. En type="search" se oculta la x nativa del navegador: la limpieza la hace clearable.

<is-input type="password" label="Contraseña" password-toggle></is-input>
<is-input type="number" label="Cantidad" min="0" max="100" step="5"></is-input>
<is-input type="search" label="Buscar" clearable></is-input>

Adornos

Para texto corto ($, kg, %) basta con prefix y suffix: se pintan atenuados y no reciben eventos. Para iconos o botones, los slots start y end. Se pueden combinar.

<is-input label="Importe" type="number" prefix="$" suffix="COP"></is-input>

<is-input label="Con iconos">
  <is-icon slot="start" icon="mdi:magnify"></is-icon>
  <is-icon slot="end" icon="mdi:filter-variant"></is-icon>
</is-input>

En JS las propiedades se llaman prefixText y suffixText: prefix ya existe en Element (prefijo de espacio de nombres XML) y no conviene pisarla.

Error y validación

error fuerza el estado visual de peligro y error-text sustituye al hint. Sin forzarlo, el campo entra solo en error cuando la validación nativa falla después de la primera interacción (blur, change o reportValidity()); si no diste error-text, se muestra el mensaje de validación del navegador. El estado se expone como :state(invalid).

<is-input error error-text="Ese correo no existe en el sistema"></is-input>

// error derivado de la validación nativa
input.reportValidity();          // marca el campo como tocado y pinta el error
input.error = true;              // o fuérzalo desde fuera

Contador de caracteres

show-count añade el contador a la derecha de la fila del hint. Con maxlength muestra n/max; sin él, solo n.

<is-input label="Titular" maxlength="40" show-count hint="Máximo 40 caracteres"></is-input>

Ancho

El ancho se controla con el token --is-field-width (heredable: puedes ponerlo en el contenedor y afecta a todos los campos de dentro). full-width lo ignora y ocupa el 100% disponible, como el fullWidth de MUI.

<div style="--is-field-width: 14rem">
  <is-input label="Estrecho"></is-input>
  <is-input label="Ancho completo" full-width></is-input>
</div>

Label a la izquierda

label-placement="start" pasa el layout a rejilla de dos columnas para formularios horizontales. --is-field-label-width fija la columna del label para que varios campos queden alineados.

<div style="--is-field-label-width: 7rem">
  <is-input label-placement="start" label="Nombre" full-width></is-input>
  <is-input label-placement="start" label="Correo" full-width></is-input>
</div>

Estados

readonly vacía el fondo y pasa el borde a discontinuo; disabled además atenúa y bloquea la interacción.
