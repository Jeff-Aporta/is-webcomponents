Rating

Valoración form-associated con paridad funcional con el Rating de MUI: precisión arbitraria, iconos propios, textos de hover, variantes de color y reset.

value: 3

<is-rating label="Satisfacción" value="3" name="rating"></is-rating>

Básicos

max define cuántos iconos hay. El tamaño no es un atributo: los iconos escalan con el font-size del contexto (o con --is-rating-size).

<is-rating label="10 iconos" max="10" value="7"></is-rating>
<is-rating value="3" style="font-size:1.5rem"></is-rating>

Precisión

precision fija la granularidad del valor: 1 (default), 0.5, 0.25 o 0.1. El icono se rellena con la fracción exacta, no por mitades. allow-half sigue funcionando como alias de precision="0.5".

<is-rating precision="0.25" value="2.75"></is-rating>
<is-rating allow-half value="2.5"></is-rating>   <!-- = precision="0.5" -->

Iconos personalizados

icon y empty-icon aceptan cualquier nombre de is-icon (Iconify, grupo:nombre). Si solo se define icon, el hueco reutiliza ese mismo icono en gris.

<is-rating icon="tabler:heart-filled" empty-icon="tabler:heart" color="danger" value="3"></is-rating>

Resaltar solo el seleccionado

Con highlight-selected-only el hover y la selección marcan únicamente el icono del valor actual, no los anteriores (equivale al ejemplo Radio group de MUI).

<is-rating highlight-selected-only value="2" show-label></is-rating>

rating.labels = ['Muy malo', 'Malo', 'Normal', 'Bueno', 'Excelente'];

Textos de hover

show-label muestra junto a los iconos el texto del valor bajo el cursor (o del valor actual si no hay hover). El texto sale, por orden de prioridad, de la propiedad getLabelText, de la propiedad labels (índice 0 = valor 1) o del atributo label-format con {v} y {max}. El mismo texto alimenta el aria-label de cada icono y el aria-valuetext del control.

hover: —

rating.labels = ['Pésimo', 'Malo', 'Normal', 'Bueno', 'Excelente'];
rating.getLabelText = (v) => `${v} punto${v === 1 ? '' : 's'}`;

rating.addEventListener('is-hover', (e) => {
  console.log(e.detail.phantomValue, e.detail.label);
});

Color

variant redefine --is-rating-color. El hueco usa siempre --is-rating-empty.

<is-rating color="success" value="3"></is-rating>
<is-rating style="--is-rating-color:#845ef7" value="3"></is-rating>

Solo lectura y fracciones

En readonly el valor no se ajusta a precision: puede mostrar cualquier fracción, que es lo habitual para una media de valoraciones.

<is-rating readonly value="3.7"></is-rating>

Reset (clearable)

Con clearable, volver a pulsar el valor ya seleccionado lo pone a 0 (solo si value >= 1). Delete y Backspace hacen lo mismo desde el teclado. Sin el atributo, el segundo clic no hace nada.

value: 3

<is-rating clearable value="3"></is-rating>

rating.clear();   // también por API

Dentro de un

El valor se envía bajo name; con value = 0 la entrada se omite y required bloquea el envío. form.reset() vuelve al valor del atributo.
