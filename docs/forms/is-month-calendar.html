Month Calendar

Documentación y demos de is-month-calendar de InSoft.

Calendario de un mes, suelto. Es la pieza que <is-date-picker> usa por dentro, y sirve por sí sola para vistas de agenda.

<is-month-calendar value="2026-08-12"></is-month-calendar>

Referencia

<is-month-calendar> — Rejilla de los 12 meses de un año (MUI MonthCalendar). Atributos: value (yyyy-mm), year, min, max (ISO), locale, columns, month-width (short|long), disabled, readonly Events: is-change detail { value, year, month }

API declarada en el módulo fuente components/forms/month-calendar.js.
