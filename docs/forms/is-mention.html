Mention

Input con autocompletado al tipear @ (usuario) o # (etiqueta). Popup se posiciona y se navega con flechas + Enter.

Básico

Disparador personalizable

Limitá los triggers con el atributo trigger.

API

const m = document.querySelector('is-mention');
m.value;          // string con tokens ya insertos: "uy @Ana esto es #urgente"
m.suggestions;    // { "@": [...], "#": [...] }
m.addEventListener('is-select', e => {
  console.log('elegiste:', e.detail.trigger, e.detail.item, e.detail.range);
});

// Sugerencias vía propiedad (alternativa al script)
m.suggestions = { '@': persons, '#': tags };

// Atributos:
// trigger   caracteres que abren el popup (default "@#")
// max-items tope del popup (default 8)
