Dropzone

Zona de arrastre con cola de archivos, preview de imagen, límite de tamaño y simulación de progreso chunked.

Básico

Arrastra o selecciona archivos; click "Simular upload" para ver el progreso.

— eventos —

API

const dz = document.querySelector('is-dropzone');
dz.files;                 // array de FileRecord
dz.addFile(file);
dz.removeFile(id);
dz.upload();              // dispara is-upload-progress por chunk
dz.addEventListener('is-files-change',   e => console.log(e.detail.files));
dz.addEventListener('is-upload-start',   e => ...);
dz.addEventListener('is-upload-progress',e => console.log(e.detail.progress));
dz.addEventListener('is-upload-end',     e => ...);
dz.addEventListener('is-error',          e => /* reason: max-size | accept | max-files */);

// Atributos
// accept, multiple, max-files, max-size (bytes), chunked
