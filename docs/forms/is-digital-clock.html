Digital Clock

Documentación y demos de is-digital-clock de InSoft.

Reloj digital: muestra la hora en formato numérico y admite selección por teclado.

<is-digital-clock value="14:30"></is-digital-clock>

Referencia

<is-digital-clock> — Selector de hora en lista (MUI DigitalClock) o en columnas de horas / minutos / segundos / AM-PM (MultiSectionDigitalClock). Atributos: value (HH:mm[:ss]), layout (list|sections), step (minutos en lista), minutes-step, seconds, ampm, hour24, min-time, max-time, skip-disabled, locale, disabled, readonly Events: is-change { value }

API declarada en el módulo fuente components/forms/digital-clock.js.
