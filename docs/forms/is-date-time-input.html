Date Time Input

Documentación y demos de is-date-time-input de InSoft.

Entrada de fecha y hora con calendario y reloj en el mismo desplegable.

Referencia

<is-date-time-input> — Fecha y hora en un solo campo con calendario y reloj lado a lado (MUI DateTimePicker). El valor es `yyyy-mm-ddTHH:mm[:ss]`. Atributos: los de is-date-input más ampm, hour24, seconds, step Events: is-change, is-show, is-hide Methods: show(), hide()

API declarada en el módulo fuente components/forms/date-time-input.js.
