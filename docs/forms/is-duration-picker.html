Duration Picker

Duración HH:MM:SS. Tres columnas con botones ±, inputs numéricos y saltos con : o Tab.

Básico

value="3725" = 1h 02m 05s

Con límites

De 1 minuto a 1:30:00, paso de 5 segundos.

API

const d = document.querySelector('is-duration-picker');
d.value;        // segundos totales
d.text;        // "01:02:05" o "02:05" si hours=0
d.hours; d.minutes; d.seconds;
d.tick(30);    // suma 30 segundos respetando límites
d.setSeconds(3600);
d.set(1, 30, 0);

d.addEventListener('is-change', e => console.log(e.detail.value, e.detail.text));

// Atributos
// value, min, max  límites en segundos
// step             incremento del botón (default 1)
