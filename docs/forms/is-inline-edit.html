Inline Edit

Texto plano que se vuelve editable al clic. Enter guarda y sale. Esc cancela y revierte. Blur guarda por defecto; usá cancel-on-blur para invertirlo.

API JS

const ie = document.querySelector('is-inline-edit');
ie.value              // string actual
ie.editing            // boolean
ie.edit()             // entra en modo edición (programáticamente)
ie.save()             // guarda y sale
ie.cancel()           // revierte y sale
ie.addEventListener('is-save',   e => console.log('nuevo:', e.detail.value, 'prev:', e.detail.previous));
ie.addEventListener('is-cancel', e => ...);
ie.addEventListener('is-edit',   () => ...);

// form-associated
// <form><is-inline-edit name="label"></is-inline-edit></form>
new FormData(form).get('label')  // = ie.value
