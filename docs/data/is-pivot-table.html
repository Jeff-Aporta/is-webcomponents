Pivot Table

Tabla pivot: agrupa por filas y columnas, agrega una medida. Soporta sum, avg, count, min y max.

API

// Atributos
// rows, cols            nombre de campo (requeridos)
// measure               nombre de campo a agregar (opcional)
// agg                   sum | avg | count | min | max   (default sum)
// format                locale para Intl.NumberFormat (default 'es-CO')
// decimals              dígitos (default 0; máximo 2)

// Datos: cualquier objeto plano serializable en <script type="application/json">
