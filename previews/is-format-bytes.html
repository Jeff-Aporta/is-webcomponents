<is-format-bytes>

Tamaños de archivo legibles. value se interpreta según unit (default byte).

Demo:

Unidades de entrada (unit)

El mismo tamaño conceptual con distinta unidad de entrada.

  • byte 1024 →
  • kilobyte 1 →
  • megabyte 2.5 →
  • gigabyte 1 →
  • terabyte 1 →
  • petabyte 1 → 
<is-format-bytes value="2.5" unit="megabyte"></is-format-bytes>
<is-format-bytes value="1" unit="gigabyte"></is-format-bytes>

Display short / long

  • short (default) 512 B →
  • long 512 →
  • short 1 GiB →
  • long 1 GiB →
  • short 2.5 MB in →
  • long 2.5 MB in → 
<is-format-bytes value="1073741824" display="short"></is-format-bytes>
<is-format-bytes value="1073741824" display="long"></is-format-bytes>

Locale

  • es →
  • en →
  • de long →
  • fr long → 
<is-format-bytes locale="es" value="1536000"></is-format-bytes>
<is-format-bytes locale="en" value="1536000" display="long"></is-format-bytes>

Casos límite

  • 0 →
  • 1 byte →
  • Negativo →
  • Sin value → «» (vacío)
