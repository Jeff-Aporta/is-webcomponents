<is-data-grid>

Tabla de datos con la superficie de MUI X Data Grid: columnas tipadas, multi-orden, filtros con Y/O, quick filter, paginación, selección de filas y de rangos de celdas, edición por celda o por fila, agrupación con agregación, tree data, pivot, virtualización y exportación.

El snippet del botón muestra sólo la etiqueta <is-data-grid>; los datos y columnas se asignan por JS justo debajo. Si lo quieres autocontenido, copia este bloque (incluye columns, rows y aggregationModel con los mismos 40 registros que ves en la tabla): 


      


      

        
Columnas

        

          Tipos nativos (string, number, date, dateTime,
          boolean, singleSelect, actions) con su alineación, comparador y
          operadores por defecto. valueGetter alimenta orden y filtro, valueFormatter
          solo el texto y renderCell devuelve nodos.
        

        

          
        

        
grid.columns = [
  { field: 'name', headerName: 'Nombre', flex: 1, minWidth: 140 },
  { field: 'gross', headerName: 'Bruto', type: 'number' },
  { field: 'taxRate', headerName: 'IVA', type: 'number',
    valueGetter: (v) => v * 100, valueFormatter: (v) => `${v}%` },
  { field: 'profit', headerName: 'Margen', type: 'number',
    valueGetter: (v, row) => row.gross - row.costs },
  { field: 'hired', headerName: 'Alta', type: 'date' },
  { field: 'active', headerName: 'Activo', type: 'boolean',
    renderCell: ({ value }) => {
      const el = document.createElement('span');
      el.className = `tag-cell ${value ? 'tag-ok' : 'tag-no'}`;
      el.textContent = value ? 'activo' : 'baja';
      return el;
    } },
  { field: 'role', headerName: 'Rol', type: 'singleSelect',
    valueOptions: ['Dev', 'QA', 'PM'] },
  { field: 'acciones', type: 'actions', getActions: ({ row }) => [
    { label: 'Ver', icon: '👁', onClick: () => alert(row.name) },
    { label: 'Borrar', icon: '🗑', showInMenu: true, onClick: () => grid.updateRows([]) },
  ] },
];

      


      

        
Ancho, anclaje y grupos

        

          Arrastra el borde derecho de una cabecera para redimensionar (doble clic ajusta al contenido),
          arrastra la cabecera para reordenar y usa el menú de columna para anclar a izquierda o derecha.
          columnGroupingModel admite grupos anidados y colSpan une celdas.
        

        

          
          
          
          
          
        

        

          
        

        
grid.columnGroupingModel = [
  { groupId: 'persona', headerName: 'Persona', children: [
    { groupId: 'ident', headerName: 'Identidad', children: [{ field: 'name' }, { field: 'email' }] },
    { field: 'city' },
  ] },
  { groupId: 'dinero', headerName: 'Económico', children: [{ field: 'gross' }, { field: 'costs' }] },
];
grid.pinnedColumns = { left: ['id'], right: ['acciones'] };

      


      

        
Edición

        

          Doble clic, Enter, F2 o cualquier carácter entran en edición.
          Enter confirma, Tab confirma y salta, Esc cancela.
          preProcessEditCellProps valida en caliente y processRowUpdate confirma
          (aquí rechaza nombres vacíos). Con clipboard y undo-redo:
          Ctrl+C, Ctrl+V, Ctrl+Z y Ctrl+Shift+Z.
        

        

          
          
          
          
        

        

          
        

        

      


      

        
Selección

        

          Filas con checkbox-selection y selection-mode (single, multiple, none);
          rangos de celdas con cell-selection (arrastra o Shift+clic).
          Teclado: Shift+Space alterna fila, Shift+↑↓ extiende, Ctrl+A todo,
          Ctrl+C copia.
        

        

          
          
          
        

        

          
        

        

      


      

        
Orden y filtros

        

          Clic en la cabecera cicla sorting-order; Ctrl o Shift+clic añade
          criterios (el número indica la prioridad). El panel de filtros combina reglas con Y/O, la fila de
          header-filters filtra por columna y el quick filter exige todas las palabras.
        

        

          
          
          
          
        

        

          
        

        

      


      

        
Agrupación, agregación y tree data

        

          rowGroupingModel agrupa por columnas y aggregationModel resume
          (sum, avg, min, max, size) tanto en la
          fila de grupo como en el pie. Con tree-data más getTreeDataPath el árbol lo
          define la propia fila. → / ← y Space expanden y colapsan.
        

        

          
          
          
          
          
        

        

          
        

        

          
        

      


      

        
Pivot

        

          pivotModel cruza filas y columnas con funciones de agregación: las columnas se generan a
          partir de los valores encontrados.
        

        

          
        

        
grid.pivotModel = {
  rows: ['city'],
  columns: ['role'],
  values: [{ field: 'gross', fn: 'sum' }],
};

      


      

        
Detail panel y filas ancladas

        

          getDetailPanelContent añade la columna de expansión y despliega contenido bajo la fila
          (Ctrl+Enter también lo alterna). pinnedRows fija filas arriba y abajo,
          y row-reorder permite arrastrarlas.
        

        

          
        

      


      

        
Virtualización y carga incremental

        

          50.000 filas en el DOM solo las visibles (más overscan). getRowHeight
          permite alto variable. Al llegar al final se emite is-rows-scroll-end y, si hay
          rowsLoader, se piden más filas (modo servidor / lazy loading).
        

        

          
        

        

      


      

        
Densidad, list view y overlays

        

          density (compact, standard, comfortable) ajusta alto y padding; list-view
          con listViewColumn renderiza una sola celda por fila. Overlays: loading con
          loading-variant spinner, progress o skeleton, y los vacíos sin filas / sin resultados.
        

        

          
          
          
          
          
          
          
          
          
        

        

          
        

      


      

        
Exportación

        

          Exporta las filas filtradas y ordenadas: CSV (con BOM y delimitador configurable), Excel
          (SpreadsheetML, sin dependencias) e impresión. También está en el botón Exportar de la toolbar.
