<is-breadcrumb>

Migas de pan accesibles con marcado <nav>, ARIA roles y separador automático entre items.

Catálogo Ropa Mujer Camisetas 
<is-breadcrumb label="Catálogo">
  <is-breadcrumb-item href="/">Catálogo</is-breadcrumb-item>
  <is-breadcrumb-item href="/ropa">Ropa</is-breadcrumb-item>
  <is-breadcrumb-item href="/ropa/mujer">Mujer</is-breadcrumb-item>
  <is-breadcrumb-item href="">Camisetas</is-breadcrumb-item>
</is-breadcrumb>

SPAs — eventos de click

Sin href, los items se renderizan como texto sin enlace. Conecta tú los handlers.

Inicio Productos Detalle

Última navegación: ninguna

bc.addEventListener('click', (e) => {
  const item = e.target.closest('is-breadcrumb-item');
  if (item) console.log('item click', item.textContent.trim());
});

Iconos en items

Usa el atributo icon o el slot start.

Inicio Artículos Viajes Dashboard Usuarios Perfil 
<is-breadcrumb-item icon="mdi:home">Inicio</is-breadcrumb-item>
<is-breadcrumb-item>
  <is-icon slot="start" icon="mdi:home"></is-icon>
  Inicio
</is-breadcrumb-item>

Separador custom

Cambia el slot separator de cada item — o sólo el último que se ignora.

/ Inicio / Docs / Guía 
<is-breadcrumb-item href="/home">
  <span slot="separator">/</span>
  Inicio
</is-breadcrumb-item>

Referencia completa — <is-breadcrumb-item>

Atributos

AtributoTipoDefaultDescripción
hrefstring—Si está, renderiza <a>. href="" = current page.
targetstring—Pasado al <a>.
relstring—Pasado al <a>.
iconstring—Iconify id por defecto (sin slot start).

Slots

SlotDescripción
(default)Texto del item.
startIcono al inicio.
endIcono al final.
separatorOverride del separador de este item.

CSS Parts

PartDescripción
::part(label)Etiqueta (texto o enlace).
::part(separator)Separador.
::part(start)Wrapper del icono al inicio.
::part(end)Wrapper del icono al final.
