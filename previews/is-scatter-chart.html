Scatter Chart

<is-scatter-chart>

Muestra la relación entre dos variables con puntos en una rejilla. Ideal para correlaciones, clusters y outliers.

A diferencia de barras/líneas, cada punto es un objeto { x, y }.

Datos con JSON

<is-scatter-chart label="Students" x-label="Hours" y-label="Score">
  <script type="application/json">
    { "data": { "datasets": [{ "label": "Students", "data": [{ "x": 2, "y": 65 }, …] }] } }
  </script>
</is-scatter-chart>

Datos con JavaScript

const chart = document.querySelector('#scatterJs');
chart.config = {
  data: {
    datasets: [{
      label: 'Students',
      data: [
        { x: 2, y: 65 }, { x: 3, y: 72 }, { x: 4, y: 78 },
        { x: 5, y: 82 }, { x: 6, y: 88 }, { x: 7, y: 85 },
        { x: 8, y: 92 }, { x: 9, y: 95 },
      ],
    }],
  },
};

Múltiples datasets

Compara grupos; cada dataset recibe su color de la serie fija.

datasets: [
  { label: 'Tutored', data: [{ x: 3, y: 78 }, …] },
  { label: 'Self-study', data: [{ x: 3, y: 68 }, …] },
]

Grid y ejes

<is-scatter-chart grid="y" x-label="Temp" y-label="Sales">…</is-scatter-chart>
<is-scatter-chart without-legend without-animation>…</is-scatter-chart>
