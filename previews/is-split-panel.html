<is-split-panel>

Dos paneles adyacentes separados por un divisor arrastrable. Componente Insoft accesible, escrito en JavaScript nativo con Shadow DOM, sin frameworks.

Persistencia: con storage-key="mi-panel" el tamaño se guarda en localStorage['is-components'] como JSON compartido por todos los WC: { "is-split-panel": { "mi-panel": { "positionInPixels": 240 } } }. Sin storage-key no escribe nada.

Primary end

Con primary="end" el panel final mantiene su tamaño cuando el host cambia de dimensión; el inicial crece/se encoge. Por defecto (primary="start") es al revés.

Snap

snap define puntos de anclaje. Acepta px y %. El snap-threshold (default 12px) es la ventana de tolerancia.

</is-split-panel>

Teclado

Foco en el divisor (Tab) y luego: ←/→ mueve 1%, Shift ×10. Home/End salta a los extremos. Enter colapsa y restaura el panel primario.

API JavaScript

Como cualquier custom element, accedes con document.querySelector('is-split-panel').

PropiedadTipoDescripción
positionnumber (0-100)Posición del divisor en % (atributo reflected).
positionInPixelsnumberPosición en píxeles. Útil para persistencia.
orientation'horizontal' | 'vertical'Eje del divisor.
primary'start' | 'end' | nullPanel que mantiene tamaño al resize.
disabledbooleanBloquea drag + teclado.
snapstring"100px 50%" — anclajes separados por espacio.
snapThresholdnumberPx de tolerancia para snap. Default 12.
storageKeystringId único; persiste tamaño en localStorage['is-components'].
