<is-command-palette>

Paleta modal al estilo ⌘K / Ctrl+K. Búsqueda difusa sobre una lista de comandos configurada vía JSON.

Probalo

Buscá un comando

Apretá ⌘K / Ctrl+K, o:
↑↓ navegar ↵ ejecutar Esc cerrar

API

const cm = document.querySelector('is-command-palette');
cm.open();
cm.close();
cm.toggle();

cm.addEventListener('is-select', e => console.log(e.detail.command.title));
cm.addEventListener('is-open',   () => ...);
cm.addEventListener('is-close',  () => ...);

// Atributos
// hotkey        "mod+k" (default), "ctrl+k", "cmd+k", "mod+/", "" (desactivado)
// placeholder   texto del input
// max-results   tope de resultados (default 12)
// empty-text    texto cuando no hay resultados

// Comandos vía <script type="application/json">:
// { id, title, group, icon, hint, keywords?, disabled?, run? (función, pero
//    serializable solo con JSON.stringify — usa is-select para acciones reales)
// }

// Footer vía <div slot="footer">…</div>
