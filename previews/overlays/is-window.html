<is-window>

Ventana flotante con botones minimizar/maximizar/cerrar y drag del header. La esquina inferior derecha redimensiona cuando tiene el atributo resizable.

Escritorio

Arrastrá el header · doble-click maximiza · esquina redimensiona · doble-click en minimizada restaura

Diseño minimalista del reporte mensual: KPIs arriba, treemap al medio, tabla abajo. Probá arrastrarlo y maximizarlo.

API

const w = document.querySelector('is-window');
w.minimize(); w.restore(); w.maximize(); w.unmaximize(); w.close();

w.addEventListener('is-minimize',  () => /* guardó última posición y se fue al dock */);
w.addEventListener('is-restore',   () => /* volvió a su posición anterior */);
w.addEventListener('is-maximize',  () => /* ocupa toda la pantalla */);
w.addEventListener('is-close',     () => /* se eliminó del DOM */);

// Atributos
// title, x, y, width, height
// maximizable, minimizable, closable, resizable
// default    normal | maximized | minimized
// dock       bottom-right (default) | bottom | top | none

// z-index se autoeleva al hacer click (sigue el foco del usuario)
