Tabs cerrables

Con el atributo closable, el tab muestra una X. El evento is-tab-close burbujea.

General Cerrable Avanzado General. Cerrable. Avanzado. Restaurar tab 
group.addEventListener('is-tab-close', (e) => {
  const t = e.detail.tab;
  t.remove();
  const panel = group.querySelector(\`is-tab-panel[name="\${e.detail.name}"]\`);
  if (panel) panel.remove();
});
