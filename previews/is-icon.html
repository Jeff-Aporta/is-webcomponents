<is-icon>

API única de iconos del kit. Usa icon="grupo:nombre" (ids Iconify) o src para un SVG/imagen. Escala con font-size. Iconify se carga solo como dependencia interna.

Ejemplos

src personalizado 
<is-icon icon="mdi:home"></is-icon>
<is-icon icon="mdi:check-circle"></is-icon>
<is-icon src="/logo.svg" label="Logo"></is-icon>

Referencia

AtributoDefaultDescripción
icon—Iconify id grupo:nombre (ej. mdi:home).
label—aria-label; vacío → aria-hidden.
src—URL img/svg (gana sobre icon).
