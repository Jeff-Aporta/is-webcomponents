Referencia

<is-time-input> — Campo de hora con panel (MUI TimePicker). `panel` elige la superficie: columnas digitales (por defecto, como el picker de escritorio de MUI), lista simple o reloj analógico. Atributos: label, hint, name, value (HH:mm[:ss]), min, max, required, disabled, readonly, clearable, locale, ampm, hour24, seconds, panel (sections|list|clock), minutes-step, step, color, action-bar, placement, close-on-select Events: is-change, is-show, is-hide Methods: show(), hide()

API declarada en el módulo fuente components/forms/time-input.js.
