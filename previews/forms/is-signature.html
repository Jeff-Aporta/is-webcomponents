<is-signature>

Pad de firma manuscrita. Funciona con ratón, táctil y stylus. Exporta a PNG y SVG.

Básico

Firma del cliente

Exportar

— presioná "Exportar" para ver el resultado —

API

const pad = document.querySelector('is-signature');
pad.toDataURL('image/png');      // dataURL PNG
pad.toDataURL('image/svg+xml'); // dataURL SVG
pad.toSVG();                    // SVG inline
pad.clear();
pad.isEmpty;                    // boolean

pad.addEventListener('is-stroke-end', e => {
  console.log('dataURL al terminar trazo:', e.detail.dataURL.slice(0, 50), '...');
});

// Atributos:
// width, height      dimensiones (default 320x140)
// pen-color          color del trazo
// line-width         grosor (default 2)
// background         color de fondo (default transparent)
// hint               texto del placeholder
