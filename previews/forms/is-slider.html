<is-slider>

Control de rango form-associated con paridad funcional con el Slider de MUI: rango de dos thumbs, marks, escala no lineal, orientación vertical y track invertido.

value: 40

Continuo

Sin marks: cualquier valor del rango, redondeado al step.

 
<is-slider label="Volumen" value="30"></is-slider>
<is-slider value="30" disabled></is-slider>

Tamaños

El tamaño va en em: baja el font-size y pista, thumb y etiquetas se reducen a la vez.

 
<is-slider style="font-size:0.8em" value="70" value-label="auto"></is-slider>
<is-slider value="50" value-label="auto"></is-slider>

Discreto

marks sin valor dibuja un punto por step. shift-step define el salto de PageUp/PageDown y Shift + flechas. 

<is-slider
  label="Temperatura"
  min="10" max="110" step="10" shift-step="30"
  value="30" marks value-label="auto" format="{v}°C"
></is-slider>

Marks personalizados

marks="valor:etiqueta, …" para etiquetas propias, o la propiedad .marks = [{ value, label }]. Con step="null" los valores quedan restringidos a los marks. 

<is-slider step="null" value="20"
  marks="0:0°C, 20:20°C, 37:37°C, 100:100°C"
  value-label="auto"></is-slider>

Rango

Dos o más valores separados por coma crean un thumb por valor. disable-swap evita que se crucen y min-distance impone una separación mínima.

rango: 20 – 37

 
<is-slider value="20,37" value-label="auto" format="{v}°C"></is-slider>
<is-slider value="20,37" min-distance="10" disable-swap></is-slider>

Slider con input

Slider e is-input sincronizados en ambos sentidos.

 
slider.addEventListener('is-input', (e) => { input.value = e.detail.value; });
input.addEventListener('is-input', (e) => { slider.value = e.detail.value; });

Color

variant cambia el color de pista, thumb y burbuja.

 
<is-slider color="success" value="60"></is-slider>

Vertical

orientation="vertical". La longitud se controla con --is-slider-length. 

<is-slider orientation="vertical" value="20,37" value-label="auto"></is-slider>

Track

track="none" oculta el relleno; track="inverted" rellena el tramo complementario. 

<is-slider track="inverted" value="20,37"></is-slider>

Escala no lineal

La propiedad scale traduce el valor interno al valor mostrado. Aquí x representa 2x: cada paso duplica el almacenamiento.

Almacenamiento: 1 MB

 
const slider = document.querySelector('is-slider');
slider.scale = (x) => 2 ** x;
slider.valueLabelFormat = (bytes) => format(bytes); // 1 MB, 2 GB…
