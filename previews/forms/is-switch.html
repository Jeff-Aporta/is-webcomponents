<is-switch>

Interruptor form-associated con paridad funcional con el Switch de MUI: mismo contrato de formulario que is-checkbox, con carril y perilla deslizante, color por variant, iconos en la perilla y rótulos dentro del carril.

Notificaciones Funciones beta Bloqueado por política
Cambia un interruptor para ver el evento.

Color

variant equivale a la prop color de MUI: redefine el carril encendido, el halo de la perilla y el anillo de foco.

brand (default) neutral success warning danger 
<is-switch color="success" checked>success</is-switch>

Posición de la etiqueta

label-placement equivale a labelPlacement del FormControlLabel de MUI.

end (default) start top bottom

Para un panel de ajustes con la etiqueta a la izquierda y el interruptor pegado al borde derecho, combina label-placement="start" con ::part(base) { justify-content: space-between }.

Modo compacto Sonidos de la interfaz Guardado automático 
.settings { display: flex; flex-direction: column; }
.settings is-switch::part(base) { justify-content: space-between; }

Iconos en la perilla

icon (apagado) y checked-icon (encendido) reciben nombres de is-icon, como el ejemplo de customized switches de MUI. Al usarlos el control crece para dar sitio al glifo.

Tema claro Sincronizar Bloquear pantalla 
<is-switch icon="mdi:weather-night" checked-icon="mdi:white-balance-sunny"
  color="warning" checked>Tema claro</is-switch>

Rótulos en el carril

on-label y off-label pintan un texto corto dentro del carril, en el hueco que deja la perilla. Pensados para dos o tres caracteres.

Encendido Confirmación Formato de hora 
<is-switch on-label="ON" off-label="OFF" checked>Encendido</is-switch>

Solo lectura y deshabilitado

readonly bloquea el cambio pero mantiene el valor en el formulario y el foco navegable con Tab. disabled saca el control del orden de tabulación y no aporta entrada al FormData.

Solo lectura (encendido) Solo lectura (apagado) Deshabilitado 
<is-switch name="ro1" checked readonly>Solo lectura</is-switch>

Error y texto de ayuda

hint pinta un texto bajo el control (atributo o slot homónimo). error tiñe carril y ayuda con el color de peligro y marca aria-invalid.

Sincronización en la nube Firma electrónica Modo mantenimiento El texto de ayuda también admite un slot. 
<is-switch error hint="Actívalo para poder facturar electrónicamente." required>
  Firma electrónica
</is-switch>

Dentro de un formulario

Apagado no aporta entrada al FormData, igual que una casilla nativa. Con required reporta valueMissing.

Acepto la política de privacidad (obligatorio) Boletín semanal Registro de auditoría
Enviar Reset
Envía el formulario para ver el FormData.
<is-switch name="boletin" value="semanal" checked>Boletín semanal</is-switch>

Escala por contexto

Sin atributo size: carril y perilla se miden en em y heredan el font-size del contenedor.

0.8rem 1rem 1.35rem 
<span style="font-size:1.35rem"><is-switch checked>Grande</is-switch></span>
