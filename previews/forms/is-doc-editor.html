<is-doc-editor>

Editor por bloques tipo Notion. Tipeá / al inicio de una línea para cambiar el tipo. Enter crea otro bloque, Backspace sobre texto vacío elimina.

Básico

JSON actual


      


      

        
API

        
const doc = document.querySelector('is-doc-editor');
doc.value;          // string JSON
doc.blocks;         // array vivo
doc.addBlock('paragraph');
doc.removeBlock(id);
doc.updateBlock(id, { text: '…' });
doc.addEventListener('is-change', e => console.log(e.detail.blocks));

// Atajos en bloques
// Enter          crear bloque del mismo tipo
// Backspace      eliminar bloque si está vacío
// "/" inicio     abre menú de tipos (heading-1..3, list, todo, quote, code, divider)
// Shift+Enter    salto de línea dentro del bloque
