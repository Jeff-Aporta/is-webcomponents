<is-masked-input>

Campo de texto que aplica un patrón mientras el usuario tipea. Útil para tarjetas, fechas, teléfonos y todo formato con estructura fija.

Tokens de patrón

CharAcepta¿Requerido?Nota
00–9síDígito obligatorio.
90–9noDígito opcional.
AA–Z / a–zsíForzado a mayúsculas (case fold).
aa–znoMinúscula.
*A–Z / a–z / 0–9noAlfanumérico opcional.
cualquier otro——Literal: se imprime tal cual cuando hay datos.

Patrones comunes

API

const m = document.querySelector('is-masked-input');
m.value           // texto formateado: "1234 5678 9012 3456"
m.raw             // caracteres limpios: "1234567890123456"
m.complete        // boolean: ¿rellenó todos los slots requeridos?
m.formatted       // alias de value

m.addEventListener('is-input',    e => /* cada keystroke */);
m.addEventListener('is-complete', e => /* completó el patrón */);

// API HTML:  invisible participa en formularios vía ElementInternals
//   <form><is-masked-input name="card" pattern="0000 0000 0000 0000"></is-masked-input></form>
formData.get('card');  // texto formateado (no raw; usar raw attr si se quiere limpio)
