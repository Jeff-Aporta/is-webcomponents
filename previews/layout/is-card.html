<is-card>

Contenedor flexible con slots para media, header, body, footer y actions. Cinco apariencias y dos orientaciones. JavaScript nativo, Shadow DOM, sin frameworks.

caso mínimo Hola mundo 
<is-card>Hola mundo</is-card>

Apariencias

El atributo appearance define el tratamiento visual. Default: outlined.

outlined

Borde 1px, fondo transparente.

 filled

Fondo elevado, sin borde.

 filled-outlined

Fondo + borde.

 plain

Sin fondo ni borde, solo espaciado.

 accent

Borde lateral de color de marca.

 
<is-card appearance="accent">...</is-card>
<is-card appearance="filled-outlined">...</is-card>

Vertical con header, media y footer

Composición vertical completa. El slot media va arriba, header debajo, body en el centro y footer al final.

Horizontal

Con orientation="horizontal" el card se vuelve una fila: media a la izquierda, body crece, actions a la derecha.

Header / footer con acciones

Slots header-actions y footer-actions reservan un extremo del header/footer para botones o iconos.

API JavaScript

Como cualquier custom element, accedes con document.querySelector('is-card').

PropiedadTipoDescripción
appearanceaccent · filled · outlined · filled-outlined · plainTratamiento visual (atributo reflected).
orientationhorizontal · verticalLayout del card (atributo reflected).

cambia propiedades Hola

Cambia appearance / orientation desde los botones.
outlined filled filled-outlined accent plain toggle orientation
El log aparece al cambiar appearance u orientation.
const c = document.querySelector('is-card');
c.appearance = 'filled';
c.orientation = 'horizontal';
c.addEventListener('slotchange', e => this.log(e));

Slots

SlotDescripción
(default)Cuerpo principal (body, siempre presente).
mediaSección de medios. Vertical: arriba. Horizontal: izquierda.
headerEncabezado (solo vertical).
footerPie (solo vertical).
actionsAcciones (solo horizontal, extremo derecho).
header-actionsAcciones dentro del header (solo vertical).
footer-actionsAcciones dentro del footer (solo vertical).

CSS Parts

PartDescripción

::part(header)Contenedor del slot header.
::part(body)Contenedor del slot por defecto.
::part(footer)Contenedor del slot footer.
::part(actions)Contenedor del slot actions.
