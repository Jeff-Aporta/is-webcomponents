<is-scrollspy>

Observa la intersección de las secciones de un contenedor scrollable y va marcando el enlace correspondiente. Pensado para la navegación lateral de los previews de docs, pero sirve para cualquier nav largo.

API JS

const spy = document.querySelector('is-scrollspy');
spy.active;                // id del trigger visible, o null
spy.triggers;              // [section, ...]
spy.activate('step-2');     // marca un enlace sin scrollear
spy.refresh();              // re-registra (tras mutar el target)
// Eventos:
spy.addEventListener('is-activated',   e => console.log(e.detail.id));
spy.addEventListener('is-deactivated', e => console.log(e.detail.id));
