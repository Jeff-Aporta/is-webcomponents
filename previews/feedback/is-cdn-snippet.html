Panel reusablede enlaces CDN para un componente. Pinta 3 filas base (individual / categor\u00eda / bundle global) y, opcionalmente, una fila adicional por cada dependencia externa que el consumidor declare (CodeMirror, librer\u00edas externas, etc.). 

<is-cdn-snippet
  tag="is-button"
  category="actions"
></is-cdn-snippet>

Dependencias externas

Si tu componente necesita otra librer\u00eda para funcionar (p. ej. CodeMirror para el visor de c\u00f3digo), declara sus enlaces con el slot deps: un <script type="application/json"> con un array de objetos {name, version?, css?, js?, note?}. El componente pinta una fila por cada dep con borde y label distintos, para que se note que son REQUISITOS, no opciones del componente. 

<is-cdn-snippet tag="is-popconfirm" category="feedback">
  <script type="application/json" slot="deps">
    [
      {
        "name": "CodeMirror",
        "version": "5.65.16",
        "css": "https://cdn.jsdelivr.net/npm/codemirror@5.65.16/lib/codemirror.min.css",
        "js":  "https://cdn.jsdelivr.net/npm/codemirror@5.65.16/lib/codemirror.min.js",
        "note": "CodeMirror 5 (no 6) para mantener la API cl\u00e1sica."
      }
    ]
  </script>
</is-cdn-snippet>

Dependencias v\u00eda atributo

Si te queda m\u00e1s c\u00f3modo, tambi\u00e9n puedes pasar las deps como atributo dependencies con JSON. El slot y el atributo se MERGEAN: si pasas ambos, el atributo gana. 

<is-cdn-snippet
  tag="is-chart"
  category="data"
  dependencies='[
    { "name": "Chart.js", "version": "4.4.0",
      "js": "https://cdn.jsdelivr.net/npm/chart.js@4.4.0/dist/chart.umd.min.js" }
  ]'
></is-cdn-snippet>

M\u00faltiples dependencias

Puedes declarar N deps en el mismo array. El componente las pinta todas, en el orden dado, con su propio bloque copiable.
