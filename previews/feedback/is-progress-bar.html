Progress Bar

<is-progress-bar>

Barra de progreso determinada (value 0–100) o indeterminada.

Contador interactivo

Cada clic avanza el progreso; Reset vuelve a 0. El value y la etiqueta se actualizan en vivo.

Listo para empezar 0%
+10 −10 Reset 
let value = 0;
const bar = document.querySelector('#pbLive');

document.querySelector('#pbPlus').addEventListener('click', () => {
  value = Math.min(100, value + 10);
  bar.value = value;
  bar.label = `Progreso ${value}%`;
});

document.querySelector('#pbReset').addEventListener('click', () => {
  value = 0;
  bar.value = 0;
});
