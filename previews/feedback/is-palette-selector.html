<is-palette-selector>

Selector visual de paletas de marca. Por defecto expone las 3 paletas de styles/palettes.css; el consumidor puede pasar su propio array JSON para usar SU marca y SU CSS, y opcionalmente inyectar un trigger personalizado en el slot trigger.

 
<is-palette-selector></is-palette-selector>

Trigger personalizado (slot)

El slot="trigger" del componente permite al consumidor inyectar SU HTML para el botón. Esto es ideal cuando el botón lleva el logo de marca (dos mitades con colores) o cualquier look que el trigger interno no represente bien.

 
<is-palette-selector>
  <button slot="trigger" class="logo-trigger">
    <span class="logo-trigger__lead">in</span>
    <span class="logo-trigger__accent">soft</span>
  </button>
</is-palette-selector>

El sitio actualiza el contenido del trigger cuando cambia la paleta (lead/accent pueden cambiar con la marca). Mira el c\u00f3digo demo para ver c\u00f3mo se sincroniza.

Paletas personalizadas

Cada consumidor pasa su propio array JSON en el atributo palettes. Si una paleta incluye css, el componente inyecta la hoja bajo demanda al seleccionarla.

 
<is-palette-selector palettes='[
  {"value":"acme","label":"Acme Corp","accent":"#e03131","lead":"ac","accentLabel":"me"},
  {"value":"ocean","label":"Ocean","accent":"#0ea5e9","lead":"o","accentLabel":"cean"}
]'>
  <button slot="trigger" class="logo-trigger">
    <span data-role="lead">ac</span>
    <span data-role="accent">me</span>
  </button>
</is-palette-selector>

Items personalizados (slot "option")

El slot="option" permite al consumidor poner un <template> con el HTML para los items del dropdown. El componente clona esa plantilla por cada paleta y bindea data-palette, aria-selected, reemplaza tokens {value}, {label}, {accent}, etc. y rellena elementos con data-role="lead|accent|swatch|label|check" con los campos de la paleta.

 
<is-palette-selector>
  <template slot="option">
    <li class="my-option">
      <span data-role="swatch"></span>
      <span data-role="lead"></span>
      <span data-role="accent"></span>
      <is-icon data-role="check" icon="mdi:check-bold"></is-icon>
    </li>
  </template>
</is-palette-selector>

El data-role es un atajo: el componente rellena el contenido y color. Tambi\u00e9n puedes usar {tokens} en atributos y texto directamente: {label}, {accent}, {value}, {lead}, {accentLabel}, {leadColor}, {accentColor}, {bg}, {fg}.

Items con tokens {}

El consumidor puede controlar el render con tokens {label} / {accent} en atributos y texto. Por ejemplo, podemos pintar el label con color accent y un atributo style="background: {accent}":

 
<template slot="option">
  <li class="token-option">
    <span class="token-option__name" style="color: {accent}">{label}</span>
    <span class="token-option__hash">#{value}</span>
  </li>
</template>

Eventos

El componente emite is-palette-change cuando el usuario selecciona una paleta. detail.value trae el identificador, detail.palette trae el objeto entero.

Selecciona una paleta para ver el evento.
