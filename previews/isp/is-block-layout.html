Caja de bloque que mide su propio ancho y publica el breakpoint como data-sizew, banderas data-szw-* y las custom properties --clientw / --lerpw. Port del BlockLayout.svelte de ISP.

Redimensiona esta caja tirando de la esquina inferior derecha.

sizew actual: —

Breakpoint como atributo y como variable

El atributo data-sizew se puede estilar desde el light DOM, y --lerpw se puede interpolar con calc().

Título que crece con el ancho del contenedor

 
<is-block-layout>…</is-block-layout>

/* light DOM */
is-block-layout[data-szw-lg] .bl-title { font-weight: 700; }
.bl-title { font-size: calc(1rem + var(--lerpw, 0) * 0.75rem); }
