Configuración

Atributos, datasets, JS

Datos por <script type="application/json"> hijo o por la propiedad config. Esquema Chart.js: { type, data: { labels, datasets }, options }.

Atributos del elemento

NombreValoresDescripción
typebar · line · pie · doughnut · radar · polarArea · scatter · bubble · waterfall · funnelTipo de gráfico. Resuelto por MARK_REGISTRY al cargar chart.js.
labeltextoTítulo sobre el gráfico (también plugins.title.text).
x-label · y-labeltextoTítulos de eje.
index-axisx · yy produce barras horizontales.
stackedbooleanoApila las series.
gridauto · both · x · y · nonePor defecto solo el eje de valor.
min · maxnúmeroFija el dominio del eje de valor.
legend-positiontop · bottom · start · endUbicación de la leyenda.
without-legend · without-tooltip · without-animationbooleanoDesactivan cada parte.
variantviewerClic → abre el visor (lightbox con tortuga de animación).

Config por JavaScript

const el = document.querySelector('#jsChart');
el.config = {
  data: {
    labels: ['Q1', 'Q2', 'Q3', 'Q4'],
    datasets: [
      { label: 'Ventas', data: [420, 580, 630, 710],
        tension: 0.4, fill: true }
    ]
  }
};
