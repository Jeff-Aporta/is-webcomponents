<is-ag-grid>

Data grid estilo ag-grid.com pero vanilla web component: orden por columna, filtros, paginación, selección, edición y virtual scroll.

Básico

Click en el botón Editar de una fila dispara is-action.

Bitácora

— eventos —

Density + toolbar

Botones en la toolbar: compact · normal · comfortable. Quick filter global. Export CSV. Sin paginación (orden + filtros libres).

Agrupar + agregar

Arrastra cabeceras al panel de agrupación. Click en una fila de grupo la expande. Botones del panel: expandir/colapsar todos. Las celdas agregadas usan aggFunc por columna (default: sum para números).

Filtros por columna + HeaderMenu

Click en el ⋮ de cada cabecera: filtro (texto/número/fecha/set), pin, ocultar, autosize, agrupar. Drag del handle entre columnas para redimensionar. Drag del nombre de columna para reordenar (al body o a la izquierda del grupo).

API

const g = document.querySelector('is-ag-grid');
g.rows;                  // array vivo (read-only)
g.columns;               // column defs (read-only)
g.api.getRows();
g.api.goToPage(2);                  // legacy 1-based
g.api.setPage(1);                   // nueva (0-based)
g.api.setPageSize(20);
g.api.setQuickFilter('oferta');
g.api.setFilter('stock', 'gt', 5);  // legacy (text)
g.api.setFilterModel({ stock: { type: 'number', op: 'gt', value: 5 } });
g.api.setSortModel([{ colId: 'price', dir: 'desc' }]);
g.api.toggleSort('price', additive);
g.api.pinColumn('sku', 'left'); g.api.hideColumn('tags');
g.api.resizeColumn('price', 160); g.api.autosizeColumn('name');
g.api.reorderColumn('status', 0);
g.api.setRowGroupCols(['category']);
g.api.toggleGroup('Muebles'); g.api.expandAllGroups(); g.api.collapseAllGroups();
g.api.getSelectedRows(); g.api.selectAll(); g.api.clearSelection();
g.api.setDensity('compact');
g.api.exportCSV('grid.csv');
g.api.serializeState();             // JSON { columns, sortModel, filterModel, ... }
g.api.loadState(json);
g.api.refresh();

g.addEventListener('is-cell-click',      e => /* { row, column, value } */);
g.addEventListener('is-cell-edit',       e => /* { row, column, oldValue, newValue } */);
g.addEventListener('is-row-select',      e => /* { rows } */);
g.addEventListener('is-sort-change',     e => /* { column, direction } */);
g.addEventListener('is-filter-change',   e => /* { column, op, value } */);
g.addEventListener('is-quick-filter',    e => /* { value } */);
g.addEventListener('is-action',          e => /* { row, column, action } */);
g.addEventListener('is-page-change',     e => /* { page, pageSize } */);
g.addEventListener('is-column-reorder',  e => /* { colId, toIndex } */);
g.addEventListener('is-column-resize',   e => /* { colId, width } */);
g.addEventListener('is-column-pin',      e => /* { colId, side } */);
g.addEventListener('is-column-hide',     e => /* { colId } */);
g.addEventListener('is-state-loaded',    e => /* GridState */);

Atributos:
  rows, columns                script JSON o atributo
  get-row-id                   nombre de la propiedad como id (default `id`)
  page-size, page-size-options
  pagination                   boolean (activa pager con count)
  row-selection                single | multiple
  selectable                   boolean — checkbox
  density                      compact | normal | comfortable
  quick-filter                 texto
  group-by                     CSV de colIds iniciales
  remember-state, storage-key
  toolbar                      true | false

Tipos de columna:
  text | number | currency | date | boolean | link | badge/enum | tags | actions

Atributos por columna:
  field, header, width, align (left|right|center), flex
  sortable, resizable, hide, filterType (text|number|date|set)
  rowGroup, enableRowGroup, aggFunc (sum|avg|min|max|count|first|last)
  cellStyle (objeto CSS)
  editable (true = prompt)
  type, decimals, format, currency, dateFormat
  enumColors (map valor → color CSS)
  actions ([{ icon, label, value }, …])   type=actions

Tokens CSS en el host:
  --is-grid-row-h, --is-grid-header-h, --is-grid-header-bg,
  --is-grid-stripe, --is-grid-row-hover, --is-grid-selected,
  --is-grid-selected-bar, --is-grid-accent-row
