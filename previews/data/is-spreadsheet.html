<is-spreadsheet>

Hoja de cálculo con edición por celda, fórmulas =SUM(A1:A5) y navegación con flechas + Tab.

Click para editar · Enter bajar · Tab derecha · Esc cancelar · Flechas mover.

Hoja de ejemplo

API / fórmulas

const s = document.querySelector('is-spreadsheet');
s.value;          // string JSON con la matriz
s.addEventListener('is-change', e => {
  console.log(`[${e.detail.row},${e.detail.col}] raw=${e.detail.raw} value=${e.detail.value}`);
});

// Fórmulas soportadas (en cualquier mayúscula o minúscula)
//   =SUM(rango)        suma
//   =AVERAGE(rango)    promedio
//   =MIN(rango)        mínimo
//   =MAX(rango)        máximo
//   =COUNT(rango)      cuenta números
//   +, -, *, /         aritmética
//   =A1*B1             referencia a celdas individuales
//
// Rangos válidos:
//   A1               celda única
//   A1:B5            rectángulo
//   A1,B2,C3         lista

// Atributos: rows, cols, value (JSON), read-only
