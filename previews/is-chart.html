<is-chart>

Wrapper themed sobre Chart.js. Datos vía config o JSON hijo.

Config por JavaScript

const el = document.querySelector('#jsChart');
el.config = {
  type: 'line',
  data: {
    labels: ['Q1','Q2','Q3','Q4'],
    datasets: [{ label: 'Ventas', data: [420, 580, 630, 710] }]
  }
};
