<is-tooltip>

Tip breve anclado con for. Depende de is-popover.

<is-tooltip for="tip-target">This is a tooltip</is-tooltip>

Placement

top top right right bottom bottom left left

Trigger click / manual

Clic fuera o Escape cierra el tip.

Click to Toggle Click nuevamente o fuera para cerrar Toggle Manually Manual tooltip

Contenido HTML largo

El slot acepta markup. Útil para tips densos; preferir trigger="click" si hay enlaces o texto seleccionable.

Auditoría · tip largo

Resumen de cumplimiento

Este tip muestra contenido enriquecido para revisar wrapping, contraste y dismiss al clic fuera.

  • Tokens --is-* y tipografía del tema
  • Máximo ancho vía --max-width
  • Enlace de ejemplo: ARIA tooltip

Última revisión: sprint actual · owner: Design System
