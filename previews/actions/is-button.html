Solo icono

Cuando el botón tiene un solo elemento hijo y nada de texto, el custom element aplica automáticamente el state :state(icon-button) y se vuelve cuadrado.

Tip: usa siempre title="..." en icon-only para accesibilidad (label del tooltip + nombre accesible).

Como enlace

Con href el botón se renderiza como <a>. Conserva variant, appearance, pill y demás atributos. y soporta target, rel y download.

Nota: cuando hay href, el componente aplica el state :state(link) que puedes usar en CSS para overrides específicos.

En formularios

El componente es form-associated: type="submit" envía el form, type="reset" lo resetea, name/value viajan con los datos, y se asocia a un <form> con form="id".

Custom States

El componente expone cuatro custom states para CSS condicional desde fuera del shadow.

StateSelectorCuándo se aplica
disabled:state(disabled)Atributo disabled o loading, o form deshabilitado.
loading:state(loading)Atributo loading.
link:state(link)Atributo href presente (se renderiza como <a>).
icon-button:state(icon-button)Un solo elemento hijo, sin texto.

Ejemplo de uso

/* afecta solo cuando está loading */
is-button:state(loading) {
  --is-button-border-radius: 999px;
}

/* afecta solo cuando es link */
is-button:state(link)::part(button) {
  text-decoration: underline;
}

/* afecta solo cuando es icon-only */
is-button:state(icon-button) {
  --_hpad: 0;
}

CSS Parts

Pseudo-elementos estilizables desde fuera del shadow DOM.

PartDescripción
::part(button)El contenedor raíz (la etiqueta <button> o <a>).
::part(label)El span que envuelve el slot por defecto (el texto del botón).
::part(start)El wrapper del slot start (icono a la izquierda).
::part(end)El wrapper del slot end (icono a la derecha).
::part(caret)El ícono chevron cuando se usa with-caret.
::part(spinner)El spinner del estado loading.

Override del spinner

Cargando con spinner custom 
is-button:state(loading)::part(spinner) svg {
  stroke: var(--is-color-danger-500);
  stroke-width: 3;
}

API JavaScript

Como cualquier custom element, accedes a la instancia con document.querySelector('is-button').

Métodos

MétodoDescripción
click()Nativo. Dispara un click programático.
focus(options?)Nativo. Foco en el botón.
blur()Nativo. Quita el foco.
setFocus(options?)Helper equivalente a focus() (misma signature).
checkValidity()Validez (form-associated).
reportValidity()Muestra mensaje de validación del form.
setCustomValidity(msg)Marca error custom para validación del form.

Propiedades de validación (de ElementInternals)

btn.validity            // ValidityState
btn.validationMessage    // string
btn.willValidate         // boolean
