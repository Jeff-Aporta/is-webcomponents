<is-context-menu>

Menú anclado al clic derecho sobre un elemento. Compatible con cualquier árbol DOM: target por selector.

Básico

Clic derecho aquí →

Sobre varios ítems

Aplica el mismo context-menu a cada fila del listado. El menú sabe qué fila disparó.

  • Inventario2026-07
  • Cartera vencida2026-07

API

const menu = document.querySelector('is-context-menu');
menu.openAt(x, y);   // programa el menú en una posición
menu.close();
menu.isOpen;

menu.addEventListener('is-select', e => {
  console.log('elegido:', e.detail.value);   // valor de data-value o texto
  console.log('item:', e.detail.item);
});

// items via slot
<is-context-menu for="#canvas">
  <button class="item" data-value="open">Abrir</button>
  <button class="item" data-value="delete">Eliminar</button>
</is-context-menu>
