<is-barcode>

Genera códigos de barras en SVG puro. Soporta EAN-13 (productos) y Code 128 (alfanumérico). QR queda como siguiente paso vía lib externa.

EAN-13 (productos)

Calcula dígito verificador automáticamente si pasás 12 dígitos.

Code 128 (general)

Personalización

API

// Atributos
// value        texto a codificar (requerido)
// type         ean13 | code128 (default code128)
// height       alto en píxeles (default 60)
// fg           color de barras
// bg           fondo (default transparent)
// show-text    imprime el texto debajo
// quiet        zonas de silencio EAN13 en módulos (default 9)

// API JS
// Acceso al SVG: bar.shadowRoot.querySelector('svg')
