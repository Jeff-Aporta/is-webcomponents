<is-qrcode>

QR en SVG. Carga bajo demanda la lib qrcode-generator (MIT, esm.sh) — sin esa red no funciona.

Básico

Personalizar

Exportar a PNG

const qr = document.querySelector('is-qrcode');
const dataURL = await qr.dataURL('image/png');
// descargar, pegar en input[type=file], etc.

API

// Atributos
// value        texto a codificar (requerido)
// level        L | M | Q | H   (default L)
// cell         tamaño en píxeles de cada módulo (default 4)
// margin       módulos de zona de silencio (default 2)
// fg, bg       colores

// API JS
qr.svg;        // nodo SVG
qr.dataURL('image/png').then(url => /* … */);

// Dependencias
// Carga qrcode-generator@1.4.4 desde esm.sh. Si tu build no tiene
// red, vendelo o usa otro loader.
