Referencia

<is-breadcrumb-item> — un paso individual dentro de un <is-breadcrumb>. Si tiene `href` (incluido `href=""`), el item se renderiza como <a href>. Con `href=""` se marca como current page (aria-current="page", CSS [current]). Si no tiene href, se renderiza como <span> (SPAs: el desarrollador maneja eventos). Atributos href string — opcional: el item se vuelve enlace. "" = current page. target string — opcional. rel string — opcional. icon string — opcional: Iconify id para icono al inicio si no se usa slot start. Slots (default) texto del item. start icono propio al inicio (gana sobre icon). end icono propio al final. separator override del separador (chevron-right por default). CSS Parts: ::part(label) ::part(separator) ::part(start) ::part(end)

API declarada en el módulo fuente components/navigation/breadcrumb-item.js.
