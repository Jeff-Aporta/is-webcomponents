Componente <iswc-er-diagram> en modo lectura. Aristas dashStyle: "dashed" animan via CSS embebido en el SVG. Mix de rutas (straight, orthogonal-h, orthogonal-v) y estilos por arista.

Arquitectura lite / full con core compartido:

  • er-archify.ts — funciones puras: spec, layout, route helpers, serialización determinista, CSS embebible.
  • <iswc-er-diagram> — LITE. Renderiza SVG desde el payload. Sin UI de edición.
  • <iswc-er-editor> — FULL. Compone <iswc-er-diagram> en su shadow DOM y añade: state, drag, click-to-connect, multi-select, undo/redo, panel de estilos, export JSON/SVG.

Garantía visual: mismo payload → mismo SVG en ambos componentes (comparten spec, layout y SVG builder).
