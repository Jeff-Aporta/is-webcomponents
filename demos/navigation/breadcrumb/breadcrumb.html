Demo — <is-breadcrumb> y <is-breadcrumb-item>

Landmark <nav> con aria-label, separador configurable y soporte para href, target, aria-current="page".

Básico

Ruta típica con un item current (href="") y un icono en el primer paso.

Label custom

El atributo label sobrescribe el aria-label del nav (default: "Ruta").

Items sin href

Sin href, el item se renderiza como <span> (el host controla la navegación vía eventos).

Separator override

Slot separator reemplaza el chevron-right por defecto.

Target / rel

Item con target="_blank" y rel="noopener" para links externos.

Estado: customElements.whenDefined('is-breadcrumb') resuelto. Landmark con aria-label.
