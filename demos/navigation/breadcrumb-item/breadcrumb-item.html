Demo — <is-breadcrumb-item>

Item individual: href → <a>, href="" → current, sin href → <span>. Slots: start, end, separator.

Estados básicos

Sin href
Con href
Current (href="")
target=_blank

Icono

El atributo icon inyecta un <is-icon> interno en el slot start (si start está vacío).

icon="mdi:home"
current + icon

Slots

Slot start tiene precedencia sobre el atributo icon.

slot=start
slot=end
slot=separator

Toggle: quitar/poner el atributo href para alternar entre <a> y <span>.
