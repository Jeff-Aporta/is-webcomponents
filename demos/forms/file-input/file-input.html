<is-file-input> · Input de archivo con drag-and-drop

Dropzone accesible con role=button, lista de archivos y validación form-associated (required, disabled).

Básico (un solo archivo)

Atributos label, hint, accept restringen el tipo de archivo.

Múltiple (varios archivos)

Atributo booleano multiple activa la selección de varios archivos.

Requerido

required + sin archivos → el componente queda :invalid y valueMissing.

Deshabilitado

disabled cierra el dropzone y bloquea el input nativo.
