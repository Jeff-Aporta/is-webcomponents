Cada demo es self-contained: importa los bundles desde dist/cdn/forms/ y funciona con cualquier servidor estático. Para los tests usa el servidor de demos (scripts/serve-demos.mjs) y corre las suites con Playwright + Stagehand.

Convenciones de los tests:

  • <componente>.test.mjs — suite funcional (smoke + interacciones + estado + accesibilidad)
  • <componente>.stagehand.test.mjs — rubric visual determinista (sin LLM por defecto; Stagehand LLM opt-in con STAGEHAND=1)
