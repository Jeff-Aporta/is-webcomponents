<is-duration-picker> · Selector de duración HH:MM:SS

Botones +/− por celda · edición directa en horas / minutos / segundos · tick() suma respetando límites · eventos is-input y is-change.

Básico (1h 30m)

Atributo value en segundos. El getter text devuelve HH:MM:SS (o MM:SS si horas=0).

Con límites y step

min=0, max=3600 (1h), step=5. Las pulsaciones rápidas respetan el límite superior.

Control programático (set / text)

set(h, m, s) asigna; text devuelve el formato legible.

Pulsa "Leer básico" para inspeccionar el valor.
