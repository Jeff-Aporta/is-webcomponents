# tests/e2e — el recorrido completo

Los recorridos de punta a punta: la galeria, las demos, el recorrido de la UX y los flujos de
los componentes con interaccion.

## Como se escriben

- `deno task test:e2e` (o `deno task test:all:full`).
- El motor esta en `tests/.audit/e2e/`: Stagehand y Playwright.
- Cada recorrido dice que se espera y que se comprueba.
