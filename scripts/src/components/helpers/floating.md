# `<iswc-floating>`

## Propósito

Posicionamiento anclado interno. No es API de producto: en apps se usa `<iswc-popover>` o `<iswc-tooltip>`.

## Cuándo usarlo

Cuando el componente padre ya está en la pantalla y este tag es la pieza que le falta.

## Cuándo no usarlo

No lo reimplementes ni lo uses para sustituir al padre. La guía del padre documenta el conjunto.

## Ejemplo mínimo

```html
<iswc-floating></iswc-floating>
```
